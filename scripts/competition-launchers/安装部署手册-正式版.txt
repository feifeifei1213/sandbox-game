沙盘经营系统正式版安装部署手册
==============================

一、这份手册给谁看
------------------
这份手册是给第一次在管理员电脑上安装正式版的人看的。
如果你是比赛当天只负责开赛和操作系统的管理员，请看“操作手册”，不要看这份。

这份手册解决的是：
1. 管理员电脑怎么准备数据库
2. 正式包应该放到哪里
3. 如果电脑上已有旧比赛数据，怎么先备份
4. 第一次怎么验证系统能正常打开


二、安装前先确认
----------------
请先确认管理员电脑满足下面这些条件：
1. 是 Windows 电脑
2. 你有这台电脑的软件安装权限
3. 这台电脑和后续玩家电脑会处于同一局域网
4. 电脑磁盘里有 `E:` 盘
5. MySQL root 密码已经确定为 `123456`

如果以上任意一条不满足，请先处理完再继续。


三、你将收到哪些文件
--------------------
你会收到三类内容：
1. 沙盘系统正式包
2. 启动脚本和手册
3. 如有旧比赛数据，还会使用备份脚本

你不需要理解源码，也不需要自己编译程序。


四、第一步：安装并启动 MySQL
-----------------------------
这一步是最关键的一步。
正式版程序默认会连接管理员电脑本机的 MySQL。

你需要完成以下目标：
1. 管理员电脑上有 MySQL 服务
2. 这个服务可以正常启动
3. root 密码为 `123456`

建议：
1. 如果你已经会安装 MySQL，就正常安装
2. 建议把服务启动类型设为“自动”
3. 启动脚本会自动识别常见服务名：`SandboxGameMySQL / MySQL / MySQL80 / MySQL57 / MariaDB`
4. 如果你的 MySQL 服务名是自定义的，再按需编辑启动脚本顶部的 `MYSQL_SERVICE` 变量

安装完成后，请先确认：
1. 在 Windows 服务列表里能看到 MySQL 服务
2. 这个服务当前状态是“正在运行”


五、第二步：创建正式比赛数据库
------------------------------
打开你的 MySQL 管理工具，或者使用命令行，创建下面数据库：

1. `sandbox_game_competition`

只要数据库名字完全一致即可。
不要改成别的名字。

如果管理员电脑以前已经跑过比赛，不要直接复用旧比赛数据库。请先备份旧库，再为新比赛创建新的数据库。


六、第三步：如果已有旧比赛数据，先备份
--------------------------------------
如果管理员电脑已经做过一次比赛，请先找到旧系统目录，双击旧目录或新工具包中的：

1. `备份当前比赛数据库.bat`

然后按提示输入备份文件名，例如：

1. `第一场正式比赛数据`

脚本会在当前系统目录下创建或复用 `backup` 文件夹，并生成 zip 文件。
确认 zip 文件存在后，再继续部署新系统。


七、第四步：放置正式包目录
--------------------------
请在管理员电脑上创建新目录：

1. `E:\deploy\sandbox-game-competition`

然后把沙盘系统正式包完整解压到这个新目录。
不要覆盖旧系统目录。

解压完成后，请确认目录里至少有这些内容：

1. `E:\deploy\sandbox-game-competition\bin\sandbox-game-server.exe`
2. `E:\deploy\sandbox-game-competition\bin\dbtool.exe`
3. `E:\deploy\sandbox-game-competition\frontend\dist\index.html`
4. `E:\deploy\sandbox-game-competition\configs\competition.yaml`
5. `E:\deploy\sandbox-game-competition\scripts\start-competition.ps1`
6. `E:\deploy\sandbox-game-competition\scripts\backup-competition-database.ps1`
7. `E:\deploy\sandbox-game-competition\启动沙盘系统.bat`
8. `E:\deploy\sandbox-game-competition\备份当前比赛数据库.bat`


八、第五步：检查配置文件是否正确
--------------------------------
请打开正式包中的配置文件：

`E:\deploy\sandbox-game-competition\configs\competition.yaml`

请重点检查以下内容：

1. 端口：建议 `8080`，或按现场确认值填写
2. 数据库：`sandbox_game_competition`
3. 密码：与本机 MySQL root 密码一致
4. `tokenSecret` 已替换为正式随机字符串

如果你收到的正式包已经是预配置好的，一般不需要手动改。


九、第六步：首次初始化数据库
----------------------------
第一次部署时，请不要敲命令，直接双击新部署目录里的脚本。

操作：
1. 双击 `首次初始化数据库.bat`
2. 按提示输入 `INIT`
3. 等待脚本显示“初始化完成”

说明：
1. 这一步会初始化管理员账号和比赛基础配置，不会直接创建玩家组
2. 如果数据库已经初始化过，且比赛还没开始，需要重新开赛，请使用“赛前重置数据库”脚本，而不是重复做首次初始化


十、第七步：试运行
------------------
现在请不要直接手工运行 exe。
请只通过新部署目录里的 `.bat` 文件来测试。

操作：
1. 双击 `启动沙盘系统.bat`
2. 看浏览器是否自动打开
3. 看是否能进入登录页

本机测试地址一般是：
1. `http://127.0.0.1:8080/sandbox-game/login`

登录管理员账号后，在赛前配置页选择本场比赛版本包，例如生产制造版或贵宾服务版。


十一、第八步：局域网联通测试
----------------------------
找到管理员电脑的局域网 IP，例如 `192.168.1.50`。

然后从另一台同网络电脑访问：
1. `http://192.168.1.50:8080/sandbox-game/login`

如果其他电脑打不开，请检查：
1. 管理员电脑防火墙是否已放行 `8080`，或配置文件中的实际端口
2. 两台电脑是否在同一局域网


十二、如果安装部署时遇到问题
----------------------------
请按这个顺序检查：
1. MySQL 服务是否存在，且服务名是否属于脚本可自动识别的常见名称
2. MySQL 服务是否正在运行
3. 正式比赛数据库是否已创建
4. 正式包是否放在正确目录
5. `frontend\dist\index.html` 是否存在
6. 端口是否与配置文件一致

如果还是不行，请把报错信息反馈给交付方。


十三、安装完成后的原则
--------------------
安装部署完成后，比赛当天请主要参考“操作手册-正式版.txt”。
不要在比赛当天再随意调整数据库名、目录名、端口号或脚本内容。
