沙盘经营系统正式版操作手册
========================

一、这份手册给谁看
------------------
这份手册是给比赛当天的管理员看的。
如果你还没有完成软件安装、数据库创建和正式包解压，请先看“安装部署手册-正式版.txt”。

这份手册只解决比赛当天的日常操作，不负责安装。


二、管理员平时只需要用哪几个文件
--------------------------------
1. 启动制造业版.bat
2. 启动服务版.bat
3. 重启制造业版服务.bat
4. 重启服务版服务.bat
5. 停止全部服务.bat

说明：
1. `首次初始化制造业版数据库.bat` 和 `首次初始化服务版数据库.bat` 只在第一次部署时使用
2. 赛前重置数据库脚本是危险操作，比赛正式开始后不要使用
3. `更新制造业版前端.bat` 和 `更新服务版前端.bat` 只在收到交付方提供的“前端更新包”时使用


三、最常用的操作
----------------
1. 要开制造业比赛
双击“启动制造业版.bat”。

2. 要开服务版比赛
双击“启动服务版.bat”。

脚本会自动做这些事情：
1. 检查并启动 MySQL
2. 启动对应版本的系统服务
3. 自动打开本机登录页


四、登录页和玩家访问地址
----------------------
管理员电脑本机打开的地址一般是：
1. 制造业版：`http://127.0.0.1:18080/sandbox-game/login`
2. 服务版：`http://127.0.0.1:28080/sandbox-game/login`

给玩家发地址时，不能发 `127.0.0.1`。
要把 `127.0.0.1` 换成管理员电脑在局域网里的 IP。

例如：
1. 制造业版：`http://192.168.1.50:18080/sandbox-game/login`
2. 服务版：`http://192.168.1.50:28080/sandbox-game/login`


五、如果收到“前端更新包”该怎么做
--------------------------------
只要交付方明确告诉你“这次只是改页面文字、字号、颜色、提醒样式”，就使用前端更新包，不要重装正式版。

操作顺序：
1. 先关闭浏览器里的相关页面
2. 把更新包解压到任意本地临时目录
3. 不要把更新包直接解压到 `D:\deploy\sandbox-game-shengchan` 或 `D:\deploy\sandbox-game-guibing`
4. 在更新包里双击对应脚本：
   - 制造业版：`更新制造业版前端.bat`
   - 服务版：`更新服务版前端.bat`
5. 脚本会自动完成：
   - 停止旧服务
   - 自动创建 `D:\deploy\_backup\...` 备份目录
   - 备份当前前端
   - 覆盖新前端
   - 尝试自动重启服务
6. 更新完成后，重新打开页面，并按 `Ctrl+F5` 强制刷新

说明：
1. 前端更新包必须同时带有脚本和 `frontend\dist\`，不能只收到一个 `.bat`
2. 如果脚本提示找不到 `frontend\dist\index.html`，说明更新包不完整
3. 如果脚本提示找不到正式版目录，说明管理员电脑上的正式包目录不对，先联系交付方


六、什么时候用“重启服务”脚本
----------------------------
出现下面这些情况时，先用“重启服务”脚本，不要急着重置数据库：
1. 网页打不开
2. 登录后页面报错
3. 页面卡住，怀疑服务没有正常响应
4. 浏览器能打开，但操作明显异常

对应关系：
1. 制造业版出问题：双击“重启制造业版服务.bat”
2. 服务版出问题：双击“重启服务版服务.bat”

重启服务不会清空比赛数据。


七、什么时候绝对不要重置数据库
--------------------------------
比赛正式开始后，不要用以下脚本：
1. 赛前重置制造业版数据库.bat
2. 赛前重置服务版数据库.bat

因为它们会清空当前比赛数据。

只有下面这种情况才可以使用：
1. 比赛还没正式开始
2. 小组数量配错了
3. 初始化做错了
4. 主持人与技术支持都同意重新开赛

执行时，脚本会要求输入 `RESET` 再继续。
这是正常的安全确认，不是报错。


八、比赛结束后怎么停
--------------------
比赛结束后，如果需要关掉系统，双击“停止全部服务.bat”。

这个脚本会：
1. 停掉制造业版服务
2. 停掉服务版服务
3. 不会停止 MySQL


九、管理员遇到问题时的处理顺序
------------------------------
请按这个顺序处理，不要跳步：
1. 先确认自己打开的是正确版本的脚本
2. 如果只是网页异常，先用“重启服务”脚本
3. 如果是页面文字或样式更新，先确认交付方给的是“前端更新包”，再双击对应更新脚本
4. 如果脚本提示找不到目录、找不到配置文件、找不到 MySQL 服务，先联系安装部署人
5. 如果比赛还没开始，且确认要重来，才能使用“赛前重置数据库”脚本
6. 如果比赛已经开始，不要自行重置数据库，先联系交付方或技术支持


十、最后一句话
--------------
比赛当天只要记住这四条就够了：
1. 开赛用“启动”
2. 网页异常先“重启”
3. 文字和样式小改动用“前端更新包”，不要重装
4. 比赛开始后不要“重置数据库”
5. 结束时用“停止全部服务”
