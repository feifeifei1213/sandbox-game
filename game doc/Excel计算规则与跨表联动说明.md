### 2.2 管理员汇总工作簿结构

汇总工作簿目前主要承载一张年度汇总表：

- 行：`第一组` 到 `第十组`
- 列：`第一年` 到 `第八年`
- 每年 3 个指标：`收入 / 利润 / 权益`

当前 Excel 中，汇总表抓取的是各组各年财报中的固定单元格，而不是经营表。

## 3. 数据流总览

当前 Excel 的主链路可以概括为：

```text
初始年财报
  -> 0年经营
  -> 0年财报
  -> 1年经营
  -> 1年财报
  -> ...
  -> 8年经营
  -> 8年财报
  -> 统计汇总
```

可以把它理解成 4 层：

1. `初始基线层`
   初始年财报给后续所有年度提供起始基数
2. `年度经营层`
   经营表记录某一年的经营动作、累计值和现金流
3. `年度财报层`
   财报表把经营结果转成损益表和资产负债表
4. `管理员汇总层`
   汇总表只读取财报结果，不直接读取经营过程数据

## 4. 各表角色定义

### 4.1 初始年财报

作用：

- 定义游戏起点
- 为 `0年经营` 提供上一年所得税、现金、资产、负债、权益等基数

当前可确认结论：

- 它不是普通年度结束后自动生成的财报，而是系统初始状态
- 在产品设计上更适合归为“管理员初始化数据”

### 4.2 N年经营表

作用：

- 承载某一年的经营录入
- 汇总年初、季度、年末的经营动作
- 自动计算现金流、费用汇总、贷款余额、折旧、衍生指标

它本质上是：

- 一张“经营过程表”
- 不是最终排名依据
- 但它是当年财报的直接数据来源

### 4.3 N年财报表

作用：

- 将经营表结果转成标准财务结果
- 输出当年 `收入 / 利润 / 权益 / 资产 / 负债 / 现金 / 应收`
- 为下一年经营表提供承接基数

它本质上是：

- 一张“年度结果确认表”
- 是汇总页的直接数据来源

### 4.4 汇总表

作用：

- 按组、按年汇总财报核心指标
- 供管理员观察结果和排名使用

当前可确认结论：

- 汇总页只关心财报结果，不关心经营过程
- 汇总页当前抓的是 `1年财报` 到 `8年财报`
- `0年财报` 没有进入当前汇总结构

## 5. 年际传递关系

下面以 `1年经营 / 1年财报` 为例说明。`2年` 到 `8年` 只是把“上一年 sheet 名”替换掉，结构不变。

### 5.1 上一年财报 -> 当年经营

`1年经营` 对 `0年财报` 的关键引用如下：

| 当年经营单元格 | 公式 | 业务含义 |
|---|---|---|
| `M1` | `='0年财报'!C21` | 读取上年所得税，作为年初缴税基数 |
| `P10` | `='0年财报'!K7+O12-O10` | 短期负债余额 = 上年短贷 + 本年新增短贷 - 本年到期还贷 |
| `P42` | `='0年财报'!K8+O44-O43` | 长期负债余额 = 上年长贷 + 本年新增长贷 - 本年到期还款 |
| `O49` | `='0年财报'!G7+O27-O23` | 生产线残值滚动 |
| `O50` | `='0年财报'!G8+O28` | 折旧前待折资产总值 |
| `C59` | `='0年财报'!$G$13+$F$59-$I$59` | 年末现金 = 上年现金 + 本年现金收入 - 本年现金支出 |

这组引用说明：

- 每年经营表不是独立的
- 它必须建立在上一年财报已经确定的前提下
- 一旦上一年财报变化，下一年经营基线就会变化

### 5.2 当年经营 -> 当年财报

`1年财报` 对 `1年经营` 的关键引用如下：

| 当年财报单元格 | 公式 | 业务含义 |
|---|---|---|
| `C4` | `='1年经营'!O38` | 销售收入 |
| `C5` | `='1年经营'!O39` | 直接成本 |
| `C10` | `='1年经营'!O2` | 综合费用 |
| `C11` | `='1年经营'!O51` | 折旧 |
| `C16` | `='1年经营'!C60` | 财务收入/支出 |
| `C17` | `='1年经营'!C61` | 额外收入/支出 |
| `G5` | `='1年经营'!O52` | 在建生产线 |
| `G13` | `='1年经营'!C59` | 现金 |
| `K7` | `='1年经营'!P10` | 短期负债 |
| `K8` | `='1年经营'!P42` | 长期负债 |

这组引用说明：

- 财报页不是独立核算页面
- 它是经营页结果的结构化映射和再计算
- 经营页提交完成后，财报页才有完整意义

### 5.3 当年财报 -> 下一年经营

`1年财报` 又会成为 `2年经营` 的输入来源。核心承接项包括：

- 所得税
- 现金
- 应收款
- 短期负债
- 长期负债
- 生产线残值
- 待折资产
- 股东资本
- 利润留存

这说明：

- 每年结束的财报不仅影响汇总
- 还决定下一年经营的起点

### 5.4 财报 -> 汇总

汇总表以 `第一组` 的 `第一年` 为例：

| 汇总表单元格 | 公式 | 来源含义 |
|---|---|---|
| `B3` | `=SUM('[1]1年财报'!$C$4)` | 收入 |
| `C3` | `=SUM('[1]1年财报'!$C$22)` | 利润 |
| `D3` | `=SUM('[1]1年财报'!$K$19)` | 权益 |

因此当前汇总页抓取的正式口径是：

- `收入 = 财报 C4`
- `利润 = 财报 C22`
- `权益 = 财报 K19`

## 6. 经营表内部计算规则

以下仍以 `1年经营` 为例。

### 6.1 费用总计

`O2 = P5+O21+O22+O29+O33+O34+O40+O45+O48+O53`

可解释为：

- 综合费用由市场投入、变更项目、生产线拆除、人力费用、研发投入、管理体系、管理人员费、生产线维护、生产厂房租金、市场培育等构成

### 6.2 订单总额

关键公式：

- `M5 = SUM(E5:L5)`
- `M6 = SUM(E6:L6)`
- `M7 = SUM(E7:L7)`
- `M8 = SUM(E8:L8)`
- `O5 = SUM(M5:N8)`

可解释为：

- 先按区域汇总项目金额
- 再汇总得到年度订单总额

### 6.3 贷款余额

关键公式：

- `O10 = SUM(G10:N10)`，累计到期还贷
- `O12 = SUM(G12:N12)`，累计新增短贷
- `P10 = 上年短期负债 + O12 - O10`
- `P42 = 上年长期负债 + O44 - O43`

可解释为：

- 经营页中短贷和长贷都采用“上一年余额 + 本年净增减”的模式

### 6.4 生产线与折旧

关键公式：

- `O49 = 上年生产线残值 + O27 - O23`
- `O50 = 上年待折资产 + O28`
- `O51 = FIXED(O50/3,0,TRUE)`

可解释为：

- `O27` 表示本年新增转固带来的残值增量
- `O23` 表示生产线出售导致的残值减少
- 折旧按待折资产的三分之一取整

### 6.5 现金流

关键公式：

- `F59 = O12 + O23 + O36 + O44 + O47 + O58`
- `I59 = M1 + P5 + O10 + O11 + O18 + O21 + O22 + O26 + O29 + O31 + O33 + O34 + O40 + O45 + O46 + O42 + O43 + O48 + O53 + O55 + O57`
- `C59 = 上年现金 + F59 - I59`

可以拆成：

现金收入项：

- 新增短期贷款
- 生产线出售收入
- 应收账款回收
- 新增长期贷款
- 生产厂房出售
- 额外收入及奖励

现金支出项：

- 上年所得税
- 市场投入
- 短贷还款和利息
- 材料费
- 生产线调整相关支出
- 人力资源费用
- 工人工资
- 研发投入
- 管理体系投入
- 管理人员费用
- 生产线维护费
- 生产厂房购买
- 长贷利息和到期还款
- 生产厂房租金
- 市场培育
- 折现费用
- 额外支出及罚款

补充说明（最终版模板）：

- 经营页主表在 `B41` 新增 `核对季末现金` 标签。
- `G41 / I41 / K41 / M41` 分别展示 `Q1 / Q2 / Q3 / Q4` 的季度现金核对值。
- `A59` 显示 `期末现金`，原 `B59 = 现金` 的标题布局已调整。
- 该行用于玩家线下核对，不构成系统提交闸门。

### 6.6 经营表衍生指标

经营页还计算了一些衍生指标：

| 单元格 | 公式 | 含义 |
|---|---|---|
| `K59` | `=O5/P5` | 市场回报比 |
| `M59` | `=O33/(O38+O58)` | 研发投入强度 |
| `O59` | 组合公式 | 劳动生产率 |
| `C60` | `=O11+O42+O55` | 财务收入/支出 |
| `E60` | `=O46-O47` | 厂房增减值 |
| `G60` | `=O38-O36` | 应收相关增减值 |
| `C61` | `=O58-O57` | 额外收入/支出 |
| `E61` | `=O27-O23` | 残值增减值 |
| `G61` | `=O28-O51` | 待折资产增减值 |

这里要特别注意：

- `game logic.md` 中对 `G60 / G61` 的业务命名存在混用风险
- 以 Excel 实际公式为准，当前更稳妥的解释是：
  - `G60` 对应应收相关增减
  - `G61` 对应待折资产增减

## 7. 财报表内部计算规则

### 7.1 损益表

关键公式如下：

| 财报单元格 | 公式 | 含义 |
|---|---|---|
| `C4` | `='1年经营'!O38` | 销售收入 |
| `C5` | `='1年经营'!O39` | 直接成本 |
| `C7` | `=C4-C5` | 毛利 |
| `C10` | `='1年经营'!O2` | 综合费用 |
| `C11` | `='1年经营'!O51` | 折旧 |
| `C13` | `=C7-C10-C11` | 营业利润 |
| `C16` | `='1年经营'!C60` | 财务收入/支出 |
| `C17` | `='1年经营'!C61` | 额外收入/支出 |
| `C19` | `=C13-C16+C17` | 税前利润 |
| `C21` | `=IF((FIXED(C19*C24,0)-0)<0,0,FIXED(C19*C24,0,TRUE))` | 所得税 |
| `C22` | `=C19-C21` | 年度净利润 |

其中：

- `C24` 是税率输入位
- 当前公式只真正读取 `C24`

### 7.2 资产侧

| `G7` | `='0年财报'!G7+'1年经营'!E61` | 生产线残值 |
| `G8` | `='0年财报'!G8+'1年经营'!G61` | 待折资产 |
| `G9` | `=G5+G6+G7+G8` | 总非流动资产 |
| `G13` | `='1年经营'!C59` | 现金 |
| `G14` | `='0年财报'!G14+'1年经营'!O38-'1年经营'!O36` | 应收款 |
| `G18` | `=G13-C21` | 所得税后现金 |
| `G19` | `=SUM(G14:G18)` | 总流动资产 |
| `G22` | `=G9+G19` | 总资产 |

### 7.3 负债与权益侧

关键公式如下：

| 财报单元格 | 公式 | 含义 |
|---|---|---|
| `K7` | `='1年经营'!P10` | 短期负债 |
| `K8` | `='1年经营'!P42` | 长期负债 |
| `K10` | `=K6+K7+K8` | 总负债 |
| `K15` | `='0年财报'!K15` | 股东资本 |
| `K16` | `='0年财报'!K16+'0年财报'!K17` | 利润留存 |
| `K17` | `=C22` | 年度净利润 |
| `K19` | `=K15+K16+K17` | 总股东权益 |
| `K22` | `=K19+K10` | 总负债和权益 |

### 7.4 资产负债平衡关系

财报表中存在两个最终结果位：

- `G22 = 总资产`
- `K22 = 总负债和权益`

Excel 当前会各自计算，但没有发现“若二者不相等则自动阻止提交”的现成机制。

因此从规则底稿角度，可以明确得到：

- `总资产 = 总负债+权益` 是一条应被关注的核心平衡关系
- 但它在当前 Excel 中更像结果对照，不是显式提交闸门

## 8. 手工输入边界

## 8.1 经营表

经营表中，玩家主要填写的是各阶段的经营动作数据，系统自动计算累计值和结果。

从当前模板看，经营表更接近：

- 当前阶段数据由玩家录入
- 汇总列、累计列、现金和指标列由公式计算

经营表中不建议按“单个公式单元格”定义手工输入边界，而更适合按业务阶段定义：

- 年初区
- Q1 区
- Q2 区
- Q3 区
- Q4 区
- 年末区
- 其他收支区

### 8.2 财报表

财报表的手工输入边界更清晰。

基于当前模板样式和公式引用，可确认首版财报手工输入边界为：

- `G15`：在制品
- `G16`：成品
- `G17`：材料
- `C24`：所得税税率

补充说明：

- `C24:C26` 在模板样式上属于同一输入区域
- 但当前公式真正读取的是 `C24`
- 因此产品实现时，应把税率作为一个明确字段，而不是让用户在 `C24:C26` 范围任意输入

### 8.3 初始年财报

初始年财报虽然也包含手工值，但从业务角色上更适合定义为：

- 管理员初始化数据
- 不作为普通玩家年度财报提交流程的一部分

## 9. 对系统设计有直接影响的稳定结论

### 9.1 页面可以贴 Excel，规则层不能只靠页面

原因：

- 页面结构确实适合高保真贴近 Excel
- 但真正的规则来自公式链和跨表传值
- 尤其是“上一年财报 -> 下一年经营”的承接，必须由系统状态控制

### 9.2 汇总页应以财报提交结果为正式口径

因为当前汇总页读取的是财报固定单元格：

- 收入：`C4`
- 利润：`C22`
- 权益：`K19`

因此产品上更适合定义为：

- 只有财报提交完成后，管理员汇总才更新该年正式值

### 9.3 跨年回退天然比年内回退重

因为：

- 当年财报会成为下一年经营基线
- 一旦允许在“下一年已开启后”改动上一年财报，系统就需要连锁重算后续年度

这不是页面问题，而是公式链决定的。

### 9.4 0年是链路的一部分，但不在当前汇总口径中

当前 Excel 结构显示：

- `0年经营 / 0年财报` 是正式链路的一部分
- 但汇总表当前从 `1年财报` 开始抓取

因此后续需求要单独确认：

- `0年` 是不是练习年
- 或者只是链路中的过渡年
- 以及它是否需要出现在系统正式排名中

### 9.5 订单推算工作簿的控制台链路

订单推算工作簿 `道具-订单推算（服务企业）.xlsx` 是线上订单模块的规则来源之一，不是玩家经营表或财报表的一部分。

当前工作簿结构包括：

- `订单模型`
- `数量推算`
- `市场地位（横）`
- `市场预测`
- `1年本地` 到 `8年全球` 的年度市场订单生成表

当前可确认的 Excel 链路为：

```text
市场预测 sheet 中的多年订单数量控制台
  -> 各年度市场订单生成表
  -> 市场预测 sheet 的预测展示区
```

控制台区域：

- `市场预测!O14` 存放小组数量。
- 本地市场控制区约为 `K17:O24`。
- 区域市场控制区约为 `K27:O34`。
- 全国市场控制区约为 `K37:O44`。
- 全球市场控制区约为 `K47:O54`。
- `L` 列为代办过检数量控制。
- `M` 列为两舱贵宾数量控制。
- `N` 列为商务贵宾数量控制。
- `O` 列为会员定制数量控制。
- `P` 列为四类订单数量合计，例如 `P17 = SUM(L17:O17)`。

跨表引用示例：

| 来源单元格 | 目标单元格 | 业务含义 |
|---|---|---|
| `市场预测!L17` | `1年本地!D22` | 1年本地市场代办过检订单卡数量 |
| `市场预测!M17` | `1年本地!D45` | 1年本地市场两舱贵宾订单卡数量 |
| `市场预测!N17` | `1年本地!D68` | 1年本地市场商务贵宾订单卡数量 |
| `市场预测!O17` | `1年本地!D91` | 1年本地市场会员定制订单卡数量 |
| `1年本地!V23` | `市场预测!L4` | 1年本地市场代办过检预测展示金额 |
| `1年本地!V46` | `市场预测!M4` | 1年本地市场两舱贵宾预测展示金额 |
| `1年本地!V69` | `市场预测!N4` | 1年本地市场商务贵宾预测展示金额 |
| `1年本地!V92` | `市场预测!O4` | 1年本地市场会员定制预测展示金额 |

年度市场订单生成表示例：

- `1年本地!C4 = IF(D22>=1,RANDBETWEEN(D23,J23),0)`，表示当该类订单卡数量大于等于 `1` 时，按区间随机生成订单数量。
- `1年本地!V23` 汇总该产品生成出的订单金额，用于回写市场预测展示区。

由此得到的系统口径：

- 多年订单数量控制台是订单数量主来源，系统不应再在年度订单管理页维护另一套独立数量。
- 市场预测由多年订单数量控制台和订单生成公式链产生，是玩家端市场投入前的只读趋势展示。
- 系统展示市场预测时固定按 `1~3年 / 4~5年 / 6~8年` 三段组织，不受管理员配置的最终年份裁剪。
- 市场预测页中的图表形态为竖状柱状图；系统管理员端与玩家端展示都应贴近该 Excel 形态：每个阶段下按市场分图，年份为横轴，四类订单为柱状系列。
- 每年开始前只生成当年正式订单池，不赛前一次性生成全部年份订单池。
- 当年正式订单池只读取该年份、管理员手动开启市场对应的控制台数量。
- 市场是否开启不由控制台数量自动推断；即使某市场在控制台中有数量，只要管理员当年未手动开启，该市场仍不生成订单、不进入抢单。
- 系统生成订单时，订单金额口径确认为 `订单金额 = 数量 × 单价`；数量为整数，单价可以有小数，但相乘后的订单金额必须为整数。该口径由后端在生成预览订单池时自动校准有效单价完成，不新增管理员逐单调整金额或单价的操作。
- Excel 右侧市场说明文字更接近静态说明或主持人维护内容，不应被理解为由公式自动推导出的规则结果。

## 10. 当前疑点与待确认项

以下内容建议在后续需求讨论中继续确认：

### 10.1 0年业务定位

当前表结构里有 `0年经营 / 0年财报`，但汇总从 `1年` 开始。

待确认：

- `0年` 是否为练习年
- `0年` 是否参与最终结果

### 10.2 税率输入交互

Excel 公式只读取 `C24`，但模板视觉上给出三种税率说明。

待确认：

- 产品实现为下拉框更清晰
- 还是完全按 Excel 展示，让用户手动填值

### 10.3 折现费用区域

`O55 = SUM(G55:N56)`

说明折现费用合计跨了两行区域，而不是单行输入。

待确认：

- 第二行具体承载什么业务含义
- 系统页面是否要完全复刻这个结构

### 10.4 经营页阶段与提交边界

Excel 本身只负责计算，不负责流程控制。

因此以下规则不是 Excel 自动给出的，而是系统层需要定义的：

- 哪些区域在 Q1 可编辑
- 哪些区域在 Q2 可编辑
- 提交后如何锁定
- 回退后如何恢复

### 10.5 财报页校验强度

Excel 会计算 `G22` 和 `K22`，但没有自动拦截机制。

待确认：

- 系统是否在财报提交时强校验 `总资产 = 总负债 + 总权益`
- 若不相等，是否直接禁止提交
