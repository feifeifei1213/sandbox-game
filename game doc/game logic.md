# 沙盘经营模拟游戏 - 业务逻辑分析文档

> 基于 `1组（3.5）.xlsx` 和 `统计-汇总.xlsx` 两份Excel文件提取

## 一、游戏总体架构

### 1.1 游戏周期
- 游戏共 **9年**：初始年 + 第0年 ~ 第8年
- 每年分 **4个季度**（Q1/Q2/Q3/Q4）
- 每年包含3个阶段：**年初工作 → 每季度工作（×4）→ 年末工作**

### 1.2 参与方
- **各组（公司）**：最多10组（第一组~第十组），每组维护自己的Excel经营表
- **裁判**：定时读取各组Excel，汇总数据到 `统计-汇总.xlsx`

### 1.3 核心数据结构
每组每年有两张表：
- **经营表**（N年经营）：记录当年所有经营操作和现金流
- **财报表**（N年财报）：年末生成的损益表 + 资产负债表

## 三、年度经营流程（经营表逻辑）

### 3.1 年初工作

#### 步骤1：支付上年度所得税
- **规则**：从现金中支付上年度所得税
- **税率**：一般企业 **25%**，高新企业 **15%**，全额弥补亏损 **0%**
- **数据来源**：上年财报的所得税金额（`上年财报!C21`）
- **计入**：综合费用

#### 步骤2：召开年度经营会议
- 调整公司战略，制定当年经营和工作计划
- 填写 **计划收入**

#### 步骤3：市场竞标
- **市场区域**（4个）：本地、全国、亚太、全球
- **项目类型**（4种）：贸易项目、集成项目、服务项目、科创项目
- 每个区域可竞标多种项目类型，填写各项目总价
- **计算规则**：
  - `区域市场订单总价 = SUM(该区域各类项目总价)`
  - `订单总额 = SUM(所有区域订单总价)`
- 需要填写 **市场投入** 金额
- 市场投入计入综合费用

### 3.2 每季度工作（Q1~Q4）

#### 步骤1：短期贷款管理
- **年利率**：10%
- 每季度可操作：
  - **到期还贷**：偿还到期的短期贷款
  - **付利息**：支付当季利息
  - **新增贷款**：申请新的短期贷款
- **年末短期负债余额** = `上年财报短期负债 + 年度新增贷款总计 - 年度到期还贷总计`
- 利息为现金支出

#### 步骤2：支付材料费用
- 支付**前一季度**订购的项目材料费，并将订单移至项目库
- 按项目类型分别记录：贸易项目、集成项目、服务项目、科创项目
- 每季度合计 = 四种项目材料费之和
- **年度材料费总计** = 四个季度合计之和
- 材料费为现金支出

#### 步骤3：项目进度更新
- 每个在建交付项目向前移动一格
- 满格的移动到项目交付库
- （纯操作步骤，无直接财务数据）

#### 步骤4：设备调整
每季度可操作：
- **变更项目**：变更在建项目
- **设备拆除**：费用 1M/条，从现金支出
- **设备出售**：从资产残值中取出相应金额到现金并记账（现金收入）
- **新设备安装**：支付安装费用（现金支出）
- **建成设备转固**：
  - 记录新增的 **设备残值**
  - 记录新增的 **待折资产**
- 年度设备残值计算 = `上年财报设备残值 + 年度新增残值 - 年度设备出售残值`

#### 步骤5：人力资源管理
- 操作：招聘/辞退/待岗/上岗/培训
- 支付招聘、辞退、培训、待岗费用
- 费用计入综合费用

#### 步骤6：设备使用与工资
- 设备空位投放材料
- 支付交付项目的设备使用人员工资
- 工资计入现金支出

#### 步骤7：新技术研发投入
- 技术研发费用
- 计入综合费用
- 影响 **研发投入强度** 指标

#### 步骤8：管理体系投入
- 质量/环境/健康费用
- 计入综合费用

#### 步骤9：下新供应链订单
- 以空桶代替，放到供应链订单上
- （纯操作步骤，无直接财务数据）

#### 步骤10：更新应收账款
- 所有应收账款向左移动一格（账期推进）
- 如应收账款进入现金区，记录现金收入

#### 步骤11：项目验收交付
- 记录 **交货订单销售额**（收入来源）
- 记录 **交货订单成本**（直接成本来源）

#### 步骤12：支付管理人员费用
- 每季度 **1M** 固定费用
- 计入综合费用

### 3.3 年末工作

#### 步骤1：长期贷款管理
- **年利率**：5%
- 操作：付利息、到期还款、办理新贷款
- **年末长期负债余额** = `上年财报长期负债 + 年度新贷款 - 年度到期还款`
- 利息计入财务支出

#### 步骤2：设备年度维护费
- 费用：**1M/条**
- 计入现金支出

#### 步骤3：数据中心资产
- **购买**数据中心：计入不动产（现金支出）
  - 数据中心A：价值 40M
  - 数据中心B：价值 32M
  - 数据中心C：价值 16M
- **出售**数据中心：从不动产取出（现金收入）

#### 步骤4：数据中心租金
- 按使用的数据中心支付租金：
  - 数据中心A：租金 4M/年
  - 数据中心B：租金 3M/年
  - 数据中心C：租金 2M/年
- 计入现金支出

#### 步骤5：设备残值计算
- **年末设备残值** = `上年财报设备残值 + 年度新增残值(O27) - 年度设备出售残值(O23)`

#### 步骤6：设备折旧
- **折旧前待折资产总价值** = `上年财报待折资产 + 年度新增待折资产(O28)`
- **折旧费** = `FIXED(待折资产总价值 / 3, 0, TRUE)`（按1/3取整，向下取整）
- 折旧费从待折资产中扣除，计入损益表折旧科目

#### 步骤7：新市场培育
- 每年可向全国、亚太、全球各投 **1M**
- 计入现金支出（综合费用）

### 3.4 其他收支（按季度记录）

#### 折现费用
- 从应收账款取出 8M，7M进入现金，1M进入折现费用
- 折现费用计入财务支出

#### 额外支出及罚款
- 裁判判定的罚款或额外支出
- 计入额外支出

#### 额外收入及奖励
- 裁判判定的奖励或额外收入
- 计入额外收入

## 四、现金流计算逻辑

### 4.1 现金余额
```
年末现金 = 上年财报现金 + 现金收入总计 - 现金支出总计
```

### 4.2 现金收入项
```
现金收入 = 新增短期贷款(O12)
         + 设备出售收入(O23)
         + 应收账款回收(O36)
         + 新增长期贷款(O44)
         + 数据中心出售(O47)
         + 额外收入及奖励(O58)
```

### 4.3 现金支出项
```
现金支出 = 上年所得税(M1)
         + 市场投入(P5)
         + 到期还贷-短期(O10)
         + 短期利息(O11)
         + 材料费(O18)
         + 变更项目费(O21)
         + 设备拆除费(O22)
         + 新设备安装(O26)
         + 人力资源费(O29)
         + 工人工资(O31)
         + 技术研发(O33)
         + 管理体系(O34)
         + 管理人员费(O40)
         + 设备维护费(O45)
         + 数据中心购买(O46)
         + 长期利息(O42)
         + 长期到期还款(O43)
         + 数据中心租金(O48)
         + 市场培育(O53)
         + 折现费用(O55)
         + 额外支出及罚款(O57)
```

## 六、财报生成逻辑（财报表）

### 6.1 损益表

```
销售收入     = 经营表.交货订单销售额(O38)
直接成本     = 经营表.交货订单成本(O39)
毛利         = 销售收入 - 直接成本
综合费用     = 经营表.综合费用(O2)
折旧         = 经营表.折旧费(O51)
营业利润     = 毛利 - 综合费用 - 折旧
财务收入/支出 = 短期利息(O11) + 长期利息(O42) + 折现费用(O55)
额外收入/支出 = 额外收入(O58) - 额外罚款(O57)
税前利润     = 营业利润 - 财务收支 + 额外收支
所得税       = IF(税前利润 × 税率 < 0, 0, FIXED(税前利润 × 税率, 0, TRUE))
年度净利润   = 税前利润 - 所得税
```

### 6.2 资产负债表 - 资产侧

```
在建设备       = 经营表.未完工设备价值(O52)
不动产（厂房） = 上年财报.不动产 + 经营表.不动产增减值(E60)
               不动产增减值 = 数据中心购买(O46) - 数据中心出售(O47)
设备残值       = 上年财报.设备残值 + 经营表.残值增减(E61)
               残值增减 = 新增残值(O27) - 出售残值(O23)
待折资产       = 上年财报.待折资产 + 经营表.应收增减(G61)
               应收增减 = 新增待折(O28) - 折旧(O51)
总非流动资产   = 在建设备 + 不动产 + 设备残值 + 待折资产

现金           = 经营表.年末现金(C59)
应收款         = 上年财报.应收款 + 销售额(O38) - 应收回收(O36)
在制品         = 手动输入
成品           = 手动输入
原料           = 手动输入
所得税后现金   = 现金 - 所得税
总流动资产     = SUM(应收款 ~ 所得税后现金)

总资产         = 总非流动资产 + 总流动资产
```

### 6.3 资产负债表 - 负债+权益侧

```
短期负债     = 经营表.短期负债余额(P10)
长期负债     = 经营表.长期负债余额(P42)
总负债       = 短期负债 + 长期负债

股东资本     = 上年财报.股东资本（不变）
利润留存     = 上年财报.利润留存 + 上年财报.年度净利润
年度净利润   = 当年损益表.年度净利润
总股东权益   = 股东资本 + 利润留存 + 年度净利润

总负债+权益  = 总负债 + 总股东权益
```

### 6.4 所得税计算规则
- **一般企业**：税率 25%（`C24 = 0.25`）
- **高新企业**：税率 15%（`C24 = 0.15`）
- **全额弥补亏损**：税率 0%（`C24 = 0`）
- 计算公式：`IF(税前利润 × 税率 < 0, 0, FIXED(税前利润 × 税率, 0))`
- 税率需要 **手工输入** 选择

## 七、关键经营指标

### 7.1 经营表中计算的指标

| 指标 | 计算公式 |
|------|----------|
| **市场回报比** | 订单总额 / 市场投入 |
| **研发投入强度** | 技术研发费 / (销售额 + 额外收入) |
| **劳动生产率** | (销售额 - 成本 + 利息 - 市场投入 - 所得税 - 变更费 - 拆除费 + 人力费 - 研发费 - 管理体系费 - 长期利息 - 维护费 - 租金 - 市场培育 - 罚款 + 奖励) / (工人工资×7 + 5) × 100 |
| **净产收益率** | 年度净利润 / 总股东权益 |
| **总产收益** | 年度净利润 / 总资产 |
| **净利润率** | 年度净利润 / 销售收入 |
| **毛利润率** | 1 - 直接成本 / 销售收入 |

### 7.2 不动产增减值
```
不动产增减值 = 数据中心购买(O46) - 数据中心出售(O47)
```

### 7.3 待折资产增减
```
待折资产增减 = 销售额(O38) - 应收回收(O36)
```
> 注：此处公式疑似存在问题，逻辑上应为新增待折 - 折旧

### 7.4 残值增减
```
残值增减 = 新增残值(O27) - 设备出售残值(O23)
```

### 7.5 应收增减
```
应收增减 = 新增待折资产(O28) - 折旧(O51)
```

## 八、年际数据传递关系

各年经营表/财报表之间存在严格的数据传递链：

```
初始年财报 → 0年经营 → 0年财报 → 1年经营 → 1年财报 → ... → 8年经营 → 8年财报
```

### 传递的关键数据：
| 从上年财报传递到当年经营 | 说明 |
|---|---|
| `上年财报!C21` → `当年经营!M1` | 上年所得税 → 年初缴税金额 |
| `上年财报!K7` → 短期负债基数 | 计算当年短期负债余额 |
| `上年财报!K8` → 长期负债基数 | 计算当年长期负债余额 |
| `上年财报!G7` → 设备残值基数 | 计算当年设备残值 |
| `上年财报!G8` → 待折资产基数 | 计算当年待折资产和折旧 |
| `上年财报!G13` → 现金余额基数 | 计算当年现金流 |

| 从当年经营传递到当年财报 | 说明 |
|---|---|
| 销售额、成本 | 损益表核心数据 |
| 综合费用、折旧 | 损益表费用项 |
| 财务收支、额外收支 | 损益表调整项 |
| 现金、应收、负债余额 | 资产负债表数据 |
| 不动产/残值/待折资产增减 | 非流动资产变动 |

- 横轴：第一年 ~ 第八年，每年3个指标（收入、利润、权益）
- 纵轴：第一组 ~ 第十组

| 数据中心 | 购买/出售金额 |
| 数据中心租金 | 租金总额 |
| 市场培育 | 各区域投入 |

### 10.3 经营表 - 其他收支手动输入项
| 步骤 | 输入项 |
|------|--------|
| 折现费用 | 按季度记录折现金额 |
| 额外支出及罚款 | 裁判判定 |
| 额外收入及奖励 | 裁判判定 |

### 10.4 财报表 - 手动输入项
| 项目 | 说明 |
|------|------|
| 在制品 | 盘点后手动填入 |
| 成品 | 盘点后手动填入 |
| 原料 | 盘点后手动填入 |
| 所得税税率 | 选择企业类型（一般25%/高新15%/亏损0%） |

## 十一、数据校验规则

### 11.1 资产负债表平衡
```
总资产 = 总负债 + 总股东权益
```

### 11.2 现金不可为负
- 每步操作后现金余额需 ≥ 0（否则需要贷款或调整策略）

### 11.3 公式交叉引用完整性
- 每年经营表引用上年财报数据
- 每年财报引用当年经营表数据
- 数据链不可断裂

## 十二、Web系统设计建议

### 12.1 角色
- **参赛组（公司）**：录入经营数据、查看自己的财报
- **裁判/管理员**：查看所有组数据、录入罚款/奖励、推进游戏阶段

### 12.2 核心功能
1. **经营数据录入**：按年度/季度分步录入各项经营数据
2. **财报自动生成**：根据经营数据和公式自动计算财报
3. **现金流实时计算**：每步操作后实时显示现金余额
4. **跨年数据自动传递**：上年财报数据自动带入下年经营表
5. **汇总排名**：实时汇总各组收入/利润/权益并排名
6. **数据校验**：资产负债表平衡检查、现金余额检查

### 12.3 游戏流程控制
- 裁判控制当前游戏处于哪一年哪个季度
- 各组只能填写当前开放的阶段
- 提交后锁定，防止修改
