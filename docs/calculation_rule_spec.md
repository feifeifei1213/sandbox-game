# 沙盘经营系统计算规则文档（正式版）

> 更新日期：2026-03-25  
> 适用方式：基于当前 Excel 模板、《Excel计算规则与跨表联动说明 v0.1》《正式需求文档（首版）》与已确认业务共识，整理成面向编码实现的规则文档。  
> 文档定位：本文件定义“规则如何算、何时生效、哪些结果进入下一张表或下一年”，作为后端规则层实现与测试回归的主依据。

## 1. 规则来源与适用边界

### 1.1 一级规则来源

- `game doc/1组 最终版.xlsx`
- `game doc/统计-汇总.xlsx`
- `game doc/Excel计算规则与跨表联动说明.md`
- `docs/requirements_spec.md`

### 1.2 适用边界

本文件只定义：

- 经营页计算口径
- 财报页计算口径
- 跨表同步规则
- 跨年承接规则
- 提交时校验规则
- 汇总与排名规则

本文件不定义：

- 桌游线下主持话术
- 页面视觉样式
- 认证与权限实现细节

### 1.3 优先级原则

- 若 Excel 公式与当前正式需求冲突，以正式需求为准。
- 若 Excel 只是提供显示方式，而系统流程并未在 Excel 中表达，则以系统需求定义的流程控制为准。
- 若后续 Excel 修改影响公式口径，必须同步更新本文件。

## 2. 总体数据链路

首版规则链路如下：

```text
初始基线
  -> 0年经营
  -> 0年财报
  -> 1年经营
  -> 1年财报
  -> ...
  -> N年经营
  -> N年财报
  -> 管理员汇总
```

可以拆成四层：

1. 初始基线层
2. 年度经营层
3. 年度财报层
4. 汇总结果层

## 3. 经营页规则

### 3.1 经营页输入与输出边界

经营页输入包含：

- 各阶段玩家手工录入的经营动作
- 额外收入/罚款等线下通知后的补录数据
- 上一年财报承接基数

经营页输出包含：

- 本年各类累计值
- 现金流结果
- 贷款余额
- 折旧相关结果
- 财务收入/支出等衍生指标
- 财报页所需的经营结果字段

### 3.2 费用总计规则

规则编号：`OP-001`

公式口径：

```text
综合费用 = 市场投入 + 变更项目 + 生产线拆除 + 人力费用 + 研发投入 + 管理体系 + 管理人员费 + 生产线维护 + 厂房租金 + 市场培育等
```

当前 Excel 对应：`O2 = P5+O21+O22+O29+O33+O34+O40+O45+O48+O53`

实现要求：

- 后端规则层负责汇总。
- 前端只展示结果，不自行计算作为正式口径。

### 3.3 订单总额规则

规则编号：`OP-002`

公式口径：

```text
先按区域汇总订单金额，再汇总得到年度订单总额
```

实现要求：

- 区域级输入由玩家填写。
- 汇总列与年度总额由规则层计算。
- 汇总结果进入经营页衍生指标区和后续财报收入相关链路。

### 3.4 贷款余额规则

规则编号：`OP-003`

公式口径：

```text
短期负债余额 = 上年短期负债 + 本年新增短贷 - 本年到期短贷
长期负债余额 = 上年长期负债 + 本年新增长贷 - 本年到期长贷
```

实现要求：

- 上年余额来自“上一年财报已提交结果”。
- 本年新增与到期金额来自经营页当年输入。
- 结果应在经营页实时展示，并在财报提交时进入负债侧。

### 3.5 生产线与折旧规则

规则编号：`OP-004`

公式口径：

```text
生产线残值 = 上年生产线残值 + 本年新增转固残值 - 本年出售残值
待折资产 = 上年待折资产 + 本年新增待折资产
折旧 = 待折资产 / 3，并按 Excel 当前口径取整
```

实现要求：

- 当前折旧口径需与 Excel 保持一致，不自行改成更“标准”的财务算法。
- 若后续老板调整 Excel 公式，这一条必须同步改规则文档与代码。

### 3.6 现金流规则

规则编号：`OP-005`

现金收入项当前至少包括：

- 新增短期贷款
- 生产线出售收入
- 应收账款回收
- 新增长期贷款
- 厂房出售
- 额外收入及奖励

现金支出项当前至少包括：

- 上年所得税
- 市场投入
- 各类还贷与利息
- 材料费
- 生产线调整相关支出
- 人力资源费用
- 工人工资
- 研发投入
- 管理体系投入
- 管理人员费用
- 生产线维护费
- 厂房购买
- 市场培育
- 折现费用
- 额外支出及罚款

现金结果口径：

```text
年末现金 = 上年现金 + 本年现金收入 - 本年现金支出
```

实现要求：

- 经营页应展示各阶段对应的季末现金核对值，供玩家线下自检。
- 现金计算结果必须有可追踪来源，方便调试和核对。

### 3.7 经营页衍生指标规则

规则编号：`OP-006`

经营页当前还包含至少以下衍生指标：

- 市场回报比
- 研发投入强度
- 劳动生产率
- 财务收入/支出
- 厂房增减值
- 应收相关增减值
- 额外收入/支出
- 残值增减值
- 待折资产增减值

实现要求：

- 首版这些指标以“展示与财报支撑”为主，不作为独立提交流程。
- 指标字段若仅用于展示，可不全部独立落关系型列，但必须能从提交快照中还原。

## 4. 财报页规则

### 4.1 财报页输入与输出边界

财报页输入包括：

- 经营页计算结果
- 财报手工项：在制品、成品、材料、所得税税率

财报页输出包括：

- 收入
- 利润
- 资产
- 负债
- 权益
- 现金
- 应收款
- 汇总页指标
- 下一年经营承接基数

### 4.2 损益表规则

规则编号：`RP-001`

当前口径为：

```text
毛利 = 销售收入 - 直接成本
营业利润 = 毛利 - 综合费用 - 折旧
税前利润 = 营业利润 - 财务收入/支出 + 额外收入/支出
所得税 = max(税前利润 * 税率, 0)
年度净利润 = 税前利润 - 所得税
```

实现要求：

- 税率输入项使用下拉，允许值仅为 `0.25`、`0.15`、`0`。
- 所得税口径与 Excel 保持一致，亏损时不计负税。

### 4.3 资产侧规则

规则编号：`RP-002`

资产侧至少包括：

- 在建生产线
- 厂房
- 生产线残值
- 待折资产
- 总非流动资产
- 现金
- 应收款
- 所得税后现金
- 在制品
- 成品
- 材料
- 总流动资产
- 总资产

补充说明：

- `在建生产线` 当前作为规则层语义字段保留，对外页面显示名以 `docs/excel_field_mapping.md` 为准。

实现要求：

- 其中在制品、成品、材料为手工输入项。
- 其他项目按经营结果与上年承接值计算。

### 4.4 负债与权益侧规则

规则编号：`RP-003`

负债权益侧至少包括：

- 短期负债
- 长期负债
- 总负债
- 股东资本
- 利润留存
- 年度净利润
- 总股东权益
- 总负债和权益

实现要求：

- 股东资本、利润留存来自上年财报承接。
- 年度净利润来自本年损益表计算。

### 4.5 财报平衡规则

规则编号：`RP-004`

财报提交前必须满足：

```text
总资产 = 总负债 + 总权益
```

实现要求：

- 首版将其作为正式提交闸门，而不是仅做展示对照。
- 不满足时返回 `422`，阻断提交。

## 5. 跨表同步规则

### 5.1 经营 -> 财报

规则编号：`SYNC-001`

经营页提交完成后，财报页读取并映射以下关键结果：

- 销售收入
- 直接成本
- 综合费用
- 折旧
- 财务收入/支出
- 额外收入/支出
- 在建生产线
- 现金
- 短期负债
- 长期负债

实现要求：

- 财报页不自行重新采集经营手工输入。
- 财报页展示以“经营结果快照 + 财报手工项”组合构成。
- `0年` 若经营页年末资产调整中的 `在建生产线` 未显式填写，则查询与计算时默认采用“初始基线”的该值作为预填起点；若玩家已显式填写 `0`，则以玩家值为准，不再回退基线值。

### 5.2 财报 -> 汇总

规则编号：`SYNC-002`

汇总页正式口径来自“已提交财报”的结果：

- 收入 = 财报 `C4`
- 利润 = 财报 `C22`
- 权益 = 财报 `K19`

实现要求：

- 未提交财报的年份不进入正式汇总。
- `0年` 不进入正式汇总。
- 财报失效时，汇总快照必须同步撤回。

### 5.3 财报 -> 下一年经营

规则编号：`SYNC-003`

下一年经营页起点来自上一年财报，至少包括：

- 所得税
- 现金
- 应收款
- 短期负债
- 长期负债
- 生产线残值
- 待折资产
- 股东资本
- 利润留存

补充说明：

- 不包含 `在建生产线 / 在建贵宾厅`。
- 按 Excel 当前公式链，财报 `G5` 仅映射“当年经营页 `O52` 的结果”，不会自动滚入下一年经营页。
- 若某年末仍存在未完工资产，需要在下一年继续按经营页当年口径手工体现；若后续要改成自动承接，属于新增业务规则，不是当前 Excel 既有链路。

实现要求：

- 若上一年财报未完成，不得开放或使用下一年正式经营起点。
- 一旦异常解锁上一年且财报失效，若下一年尚未开放可允许重提；若下一年已开放则首版禁止解锁。

## 6. 提交与校验规则

### 6.1 经营阶段提交范围

规则编号：`VAL-001`

| 提交动作 | 校验范围 |
|---|---|
| `Q1` 提交 | `年初 + Q1` |
| `Q2` 提交 | `Q2` |
| `Q3` 提交 | `Q3` |
| `Q4` 提交 | `Q4` |
| `年末` 提交 | `年末区手工项` |

### 6.2 季末现金核对展示规则

规则编号：`VAL-002`

- 经营页保留 `季末现金核对` 行。
- 最终版 Excel 中，该行标签位于 `B41`，`G41/I41/K41/M41` 分别展示 `Q1/Q2/Q3/Q4` 的季度现金核对值。
- `A59` 为 `期末现金` 标题位置，页面高保真还原时应与最终版 Excel 保持一致。
- 系统按当前经营数据与规则计算对应阶段的季末现金，只读展示给玩家。
- 玩家在线下数桌面现金后，自行与系统展示值核对。
- 系统不采集现场现金，也不因现金差异阻断提交。

### 6.3 财报校验规则

规则编号：`VAL-003`

- 财报手工项必须填写完成。
- 财报平衡关系必须成立。
- 税率必须来自允许值集合。

### 6.4 自动保存规则

规则编号：`VAL-004`

- 自动保存只保存草稿，不推进状态。
- 正式提交才改变状态、写日志、影响汇总与下一年承接。

## 7. 排名与破产规则

### 7.1 汇总与排名规则

规则编号：`GAME-001`

- 正式汇总从 `1年` 开始。
- 最终排名只在最终年份完成后产生。
- 排名依据：最终年份所有者权益由高到低。

### 7.2 破产规则

规则编号：`GAME-002`

满足以下任一条件则破产：

- 在经营阶段提交节点，现金流断裂
- 在最终年份，所有者权益为负

### 7.3 破产后的规则

规则编号：`GAME-003`

- 破产后后续年份不可编辑。
- 历史数据保留。
- 管理员汇总页标记破产。
- 玩家仍可查看历史数据。

---

## 8. 异常解锁规则

规则编号：`ADMIN-001`

- 仅管理员可执行。
- 仅允许在“下一年尚未开放前”解锁某组某年。
- 解锁后本年已锁定区域恢复可编辑。
- 若财报已提交，则财报失效。
- 若该年已进入汇总，则汇总快照撤回。
- 玩家修改后需重新提交经营阶段，必要时重新提交财报。

实现要求：

- 异常解锁是管理动作，不是普通状态。
- 必须保留解锁原因和日志。

## 9. 规则变更控制

### 9.1 可局部调整的内容

以下变化通常可局部调整，不必推翻全套设计：

- 字段显示名变化
- 页面标签变化
- 少量公式系数变化
- 个别非结构性衍生指标调整

### 9.2 必须回到需求确认的内容

以下变化一旦发生，必须同步回到需求确认流程：

- 阶段提交流程变化
- 破产规则变化
- 汇总口径变化
- 财报手工项边界变化
- 跨年承接字段变化
- 经营页或财报页结构性区块变化

### 9.3 文档联动要求

规则变化后至少同步更新：

- `docs/requirements_spec.md`
- `docs/api_design.md`
- `docs/database_design.md`
- `docs/excel_field_mapping.md`
- `docs/testing_guide.md`
- `docs/implementation_plan.md`
