# 沙盘经营系统计算规则文档（正式版）

> 更新日期：2026-05-19
> 适用方式：基于当前 Excel 模板、《Excel计算规则与跨表联动说明 v0.1》《正式需求文档（首版）》与已确认业务共识，整理成面向编码实现的规则文档。  
> 文档定位：本文件定义“规则如何算、何时生效、哪些结果进入下一张表或下一年”，作为后端规则层实现与测试回归的主依据。

## 1. 规则来源与适用边界

### 1.1 一级规则来源

- `game doc/1组 最终版.xlsx`

## 2. 总体数据链路

首版规则链路如下：

```text
初始基线
  -> 0年经营
  -> 0年财报
  -> 1年经营
  -> 1年财报
  -> ...
  -> N年经营
  -> N年财报
  -> 管理员汇总
```

可以拆成四层：

1. 初始基线层
2. 年度经营层
3. 年度财报层
4. 汇总结果层

## 3. 经营页规则

### 3.1 经营页输入与输出边界

经营页输入包含：

- 各阶段玩家手工录入的经营动作
- 管理员下发的奖励/罚款
- 正式年份订单模块生成的市场投入与已选订单金额
- 上一年财报承接基数

经营页输出包含：

- 本年各类累计值
- 现金流结果
- 贷款余额
- 折旧相关结果
- 财务收入/支出等衍生指标
- 财报页所需的经营结果字段

### 3.2 费用总计规则

规则编号：`OP-001`

公式口径：

```text
综合费用 = 市场投入 + 变更项目 + 生产线拆除 + 人力费用 + 研发投入 + 管理体系 + 管理人员费 + 生产线维护 + 厂房租金 + 市场培育等
```

当前 Excel 对应：`O2 = P5+O21+O22+O29+O33+O34+O40+O45+O48+O53`

实现要求：

- 后端规则层负责汇总。
- 前端只展示结果，不自行计算作为正式口径。

### 3.3 订单总额规则

规则编号：`OP-002`

公式口径：

```text
0年：沿用经营页现有输入与汇总口径。
1年 ~ 最终年：按订单模块中本组当年全部标段已选订单金额汇总得到年度订单总额。
```

实现要求：

- `0年` 不需要线上订单，可继续作为引导年按经营页口径填写。
- 正式年份的订单来源由年度订单模块提供，不由经营页自由填写。
- 正式年份全部标段已选订单金额汇总后进入经营页 `订单总额`。
- 正式年份当前订单模板下全部标段市场投入金额汇总后进入经营页 `市场投入`；未开启市场对应投入由系统自动按 `0` 提交，因此不会增加经营页市场投入。
- 汇总列与年度总额由规则层计算。
- 汇总结果进入经营页衍生指标区和后续财报收入相关链路。
- 如果正式年份订单竞标流程尚未结束，经营页 `Q1` 进入/提交应被拦截。

### 3.4 贷款余额规则

规则编号：`OP-003`

公式口径：

```text
短期负债余额 = 上年短期负债 + 本年新增短贷 - 本年到期短贷
长期负债余额 = 上年长期负债 + 本年新增长贷 - 本年到期长贷
```

实现要求：

- 上年余额来自“上一年财报已提交结果”。
- 本年新增与到期金额来自经营页当年输入。
- 结果应在经营页实时展示，并在财报提交时进入负债侧。

### 3.5 生产线与折旧规则

规则编号：`OP-004`

公式口径：

```text
生产线残值 = 上年生产线残值 + 本年新增转固残值 - 本年出售残值
待折资产 = 上年待折资产 + 本年新增待折资产
折旧 = 待折资产 / 3，并按 Excel 当前口径取整
```

实现要求：

- 当前折旧口径需与 Excel 保持一致，不自行改成更“标准”的财务算法。
- 若后续老板调整 Excel 公式，这一条必须同步改规则文档与代码。

### 3.6 现金流规则

规则编号：`OP-005`

现金收入项当前至少包括：

- 新增短期贷款
- 生产线出售收入
- 应收账款回收
- 新增长期贷款
- 厂房出售
- 额外收入及奖励

现金支出项当前至少包括：

- 上年所得税
- 市场投入
- 各类还贷与利息
- 材料费
- 生产线调整相关支出
- 人力资源费用
- 工人工资
- 研发投入
- 管理体系投入
- 管理人员费用
- 生产线维护费
- 厂房购买
- 市场培育
- 折现费用
- 额外支出及罚款

现金结果口径：

```text
年末现金 = 上年现金 + 本年现金收入 - 本年现金支出
```

实现要求：

- 经营页应展示各阶段对应的季末现金核对值，供玩家线下自检。
- 现金计算结果必须有可追踪来源，方便调试和核对。

### 3.6.1 第 9 步订单数量留痕不参与计算

规则编号：`OP-005A`

- `quarter.supplyChainOrderRecord` 仅记录玩家当年各季度线下放置的空桶订单数量。
- 生产制造版四类为基础产品、标准产品、精密产品、智能产品；贵宾服务版四类为代办过检服务、两舱贵宾服务、商务贵宾服务、会员定制服务。
- 记录按年独立，不读取上一年值，也不作为下一年经营承接来源。
- 该字段不计入现金收入、现金支出、收入、直接成本、综合费用、库存、应收、财报、汇总或排名。
- 该字段不生成正式订单实体，不改变订单池、市场投入、选单顺序、交付状态或市场龙头。
- 回退后只按现有阶段级重提链修改和留档，不触发额外公式重算逻辑。

### 3.7 经营页衍生指标规则

规则编号：`OP-006`

经营页当前还包含至少以下衍生指标：

- 市场回报比
- 研发投入强度
- 劳动生产率
- 财务收入/支出
- 厂房增减值
- 应收相关增减值
- 额外收入/支出
- 残值增减值
- 待折资产增减值

实现要求：

- 首版这些指标以“展示与财报支撑”为主，不作为独立提交流程。
- 指标字段若仅用于展示，可不全部独立落关系型列，但必须能从提交快照中还原。

## 4. 财报页规则

### 4.1 财报页输入与输出边界

财报页输入包括：

- 经营页计算结果
- 财报手工项：在制品、成品、材料、所得税税率

财报页输出包括：

- 收入
- 利润
- 资产
- 负债
- 权益
- 现金
- 应收款
- 汇总页指标
- 下一年经营承接基数

### 4.2 损益表规则

规则编号：`RP-001`

当前口径为：

```text
毛利 = 销售收入 - 直接成本
营业利润 = 毛利 - 综合费用 - 折旧
税前利润 = 营业利润 - 财务收入/支出 + 额外收入/支出
所得税 = max(税前利润 * 税率, 0)
年度净利润 = 税前利润 - 所得税
```

实现要求：

- 税率输入项使用下拉，允许值仅为 `0.25`、`0.15`、`0`。
- 所得税口径与 Excel 保持一致，亏损时不计负税。

### 4.3 资产侧规则

规则编号：`RP-002`

资产侧至少包括：

- 在建生产线
- 厂房
- 生产线残值
- 待折资产
- 总非流动资产
- 现金
- 应收款
- 所得税后现金
- 在制品
- 成品
- 材料
- 总流动资产
- 总资产

补充说明：

- `在建生产线` 当前作为规则层语义字段保留，对外页面显示名以 `docs/excel_field_mapping.md` 为准。

实现要求：

- 其中在制品、成品、材料为手工输入项。
- 其他项目按经营结果与上年承接值计算。

### 4.4 负债与权益侧规则

规则编号：`RP-003`

负债权益侧至少包括：

- 短期负债
- 长期负债
- 总负债
- 股东资本
- 利润留存
- 年度净利润
- 总股东权益
- 总负债和权益

实现要求：

- 股东资本、利润留存来自上年财报承接。
- 年度净利润来自本年损益表计算。

### 4.5 财报平衡规则

规则编号：`RP-004`

财报提交前必须满足：

```text
总资产 = 总负债 + 总权益
```

实现要求：

- 首版将其作为正式提交闸门，而不是仅做展示对照。
- 不满足时返回 `422`，阻断提交。

### 4.6 总监得分规则

规则编号：`RP-005`

#### 4.6.1 变量定义

| 符号 | 系统字段 / 来源 | 含义 |
|---|---|---|
| `O_y` | 当年经营页 `orderTotal`，对应经营表 `O5` | 第 `y` 年订单总额 |
| `E_y` | `reportTotalEquity`，对应财报 `K19` | 第 `y` 年当前所有者权益 |
| `S_y` | `reportBestSalesDirectorScore` | 第 `y` 年最佳销售总监得分 |
| `CEO_y` | `reportBestCeoScore` | 第 `y` 年最佳 CEO 得分 |

#### 4.6.2 最佳销售总监得分

用户确认在原累计订单总额公式基础上整体除以 `10`：

```text
S_y = (O_0 + O_1 + ... + O_y) / 10
```

为兼容系统按上一年得分递推的实现结构，应使用：

```text
S_0 = O_0 / 10
S_y = S_(y-1) + O_y / 10    （y >= 1）
```

两种表达在上一年得分已经按当前规则生成时数学等价。禁止使用：

```text
(S_(y-1) + O_y) / 10
```

错误公式会重复缩放历史得分。例如 `0年订单总额 = 100`、`1年订单总额 = 140`，正确得分为 `100/10 + 140/10 = 24`；错误递推会得到 `(10 + 140)/10 = 15`。

#### 4.6.3 最佳 CEO 得分

在原五项总监最终得分合计基础上，增加当前年份所有者权益的一半：

```text
CEO_y = reportBestMarketDirectorScore_y
      + reportBestTechnologyDirectorScore_y
      + productionHumanScore_y
      + reportBestSalesDirectorScore_y
      + reportBestCfoScore_y
      + reportTotalEquity_y / 2
```

实现边界：

- 权益项取当前年份 `reportTotalEquity / 2`，不取权益增量、上一年权益或总资产。
- `reportBestCfoScore` 当前已包含权益增量影响；CEO 新增当前权益的一半是独立加分/扣分项，按用户确认保留两条影响链，不做抵消。
- 当前所有者权益为负时，权益项为负并降低 CEO 得分。
- 销售总监和 CEO 得分不额外取整，保留公式计算产生的小数。

#### 4.6.4 年份、历史数据与回退口径

- 新公式同时适用于生产制造版与贵宾服务版，并从 `0年` 起对全部年份追溯生效。
- 历史财报查询应从 `0年` 到目标年份按当前规则递归重建总监得分，确保后续年份承接的是已经除以 `10` 的上一年销售总监得分。
- 旧财报提交 JSON、失效草稿和状态快照不做物理改写；页面查询可覆盖展示为当前规则重建值，回退重提时保存当前规则计算的新结果。
- 不新增数据库字段或迁移，继续复用现有 `reportBestSalesDirectorScore`、`reportBestCeoScore` 与 `reportTotalEquity` 字段。

#### 4.6.5 前后端一致性

- 后端财报计算器是正式结果的唯一权威来源。
- 财报页手工修改税率、库存、企业认证、生产/服务人力或关账速度时，前端可进行实时预览。
- 订单总额不会被财报页手工项修改，因此前端预览直接复用后端返回的 `reportBestSalesDirectorScore`；该值已经按新公式除以 `10`，前端不得再次除以 `10`。
- 所得税率会影响净利润及 `reportTotalEquity`，因此前端 CEO 预览必须使用当前预览计算出的 `reportTotalEquity / 2`，保证编辑态预览与提交后的后端正式结果一致。

## 5. 跨表同步规则

### 5.0 订单模块 -> 经营页

规则编号：`SYNC-ORDER-001`

适用范围：

- `0年` 不适用订单模块。
- `1年 ~ 最终年` 适用订单模块。

同步口径：

```text
经营页市场投入 = 本组本年当前订单模板下全部“市场 + 订单类型”已提交市场投入之和
经营页订单总额 = 本组本年全部标段已选订单金额之和
```

实现要求：

- 年度订单页负责当前订单模板下全部市场投入提交、订单池展示、按顺序选择订单。
- 默认开启市场由订单模板定义：贵宾模板本地市场默认开启，区域 / 全国 / 全球默认关闭；机场模板国内市场默认开启，国际市场默认关闭；管理员可手动开启或关闭。
- 未开启市场仍在玩家市场投入表中显示，但对应订单类型输入框禁用并由系统自动按 `0` 提交；绕过前端提交非 `0` 时服务端拒绝。
- 管理员可按 `年份 + 市场` 配置单市场投入上限；空值表示无上限，非空时必须为非负整数。
- 已开启且配置上限的市场，该市场下全部订单类型投入合计不得超过上限。
- 市场投入必须为非负整数，不允许小数。
- 市场投入提交入口从经营页前移到订单前置流程；经营页对应市场投入格只读带入，不再允许玩家在 `Q1` 修改。
- `0年` 不走独立市场投入提交；`1年 ~ 最终年` 必须在开标前提交当前订单模板下全部市场投入。
- 经营页只读取订单模块结果，不再在正式年份自行决定订单总额。
- 直接成本不由订单模块生成，继续由玩家在经营页填写。
- 账期字段首版只展示，不参与经营页应收账款自动计算。
- 玩家在年度订单页或本组订单展示区对已选订单执行交付操作，交付时绑定当前经营季度。
- 单个订单不允许拆分到多个季度交付；一个季度可以交付多个完整订单。
- 订单交付成功后，系统按该季度当前有效已交付订单金额合计生成经营页销售收入，公式口径为：`某季度销售收入 = 本组本年该季度 delivery_effective = true 的已交付订单金额合计`。
- 正式年份经营页销售收入为系统生成只读项，不再由玩家手工填写；直接成本继续由玩家在经营页填写。
- 经营页查询、保存、提交和快照生成前，后端均应按当前有效订单交付记录覆盖销售收入，保证经营页、财报和汇总读取同一权威来源。
- 年末未交付订单标记为 `UNFINISHED`，但首版不阻断财报提交。
- 未交付处罚规则暂未确定，首版只保留状态与规则接入口。

### 5.1 经营 -> 财报

规则编号：`SYNC-001`

经营页提交完成后，财报页读取并映射以下关键结果：

- 销售收入
- 直接成本
- 综合费用
- 折旧
- 财务收入/支出
- 额外收入/支出
- 在建生产线
- 现金
- 短期负债
- 长期负债

实现要求：

- 财报页不自行重新采集经营手工输入。
- 财报页展示以“经营结果快照 + 财报手工项”组合构成。
- `0年` 若经营页年末资产调整中的 `在建生产线` 未显式填写，则查询与计算时默认采用“初始基线”的该值作为预填起点；若玩家已显式填写 `0`，则以玩家值为准，不再回退基线值。

### 5.2 财报 -> 汇总

规则编号：`SYNC-002`

汇总页正式口径来自“已提交财报”的结果：

- 收入 = 财报 `C4`
- 利润 = 财报 `C22`
- 权益 = 财报 `K19`

实现要求：

- 未提交财报的年份不进入正式汇总。
- `0年` 不进入正式汇总。
- 财报失效时，汇总快照必须同步撤回。

### 5.3 财报 -> 下一年经营

规则编号：`SYNC-003`

下一年经营页起点来自上一年财报，至少包括：

- 所得税
- 现金
- 应收款
- 短期负债
- 长期负债
- 生产线残值
- 待折资产
- 股东资本
- 利润留存

补充说明：

- 不包含 `在建生产线 / 在建贵宾厅`。
- 按 Excel 当前公式链，财报 `G5` 仅映射“当年经营页 `O52` 的结果”，不会自动滚入下一年经营页。
- 若某年末仍存在未完工资产，需要在下一年继续按经营页当年口径手工体现；若后续要改成自动承接，属于新增业务规则，不是当前 Excel 既有链路。

实现要求：

- 若上一年财报未完成，不得开放或使用下一年正式经营起点。
- 一旦异常解锁上一年且财报失效，若下一年尚未开放可允许重提；若下一年已开放则首版禁止解锁。

## 7. 排名与破产规则

### 7.1 汇总与排名规则

规则编号：`GAME-001`

- 正式汇总从 `1年` 开始。
- 最终排名只在最终年份完成后产生。
- 排名依据：最终年份所有者权益由高到低。

### 7.2 破产规则

规则编号：`GAME-002`

满足以下任一条件则破产：

- 在经营阶段提交节点，现金流断裂
- 在最终年份，所有者权益为负

### 7.2.1 订单竞标排序规则

规则编号：`GAME-ORDER-001`

- `1年`：按当前标段的 `市场 + 订单类型` 投入从高到低排序。
- `1年` 当前标段投入相同：随机确定先后，并记录随机结果。
- `2年` 起：该市场下各标段由上一年市场龙头优先，其余参与小组按当前标段投入从高到低排序。
- 市场龙头定义为上一年该市场全部订单类型已选订单金额合计最高的小组；并列时随机确定唯一市场龙头。
- 机场模板下，国内市场龙头按上一年国内窄体 + 国内宽体已选订单金额合计计算，国际市场龙头按上一年国际窄体 + 国际宽体已选订单金额合计计算。
- 市场龙头只在对应市场生效，不跨市场。
- 市场龙头只在未破产小组中生效；若上一年市场龙头已破产，本年按没有有效市场龙头处理。
- 市场龙头只有在当前标段投入为正时才有资格；投入为 `0` 时不参与该标段任何轮次，市场投入金额仍按实际 `0` 进入经营页汇总。
- 任何非龙头小组当前标段投入为 `0` 时同样不参与该标段选单。
- 非龙头小组当前标段投入相同时，按上一年度该市场订单总额从高到低排序；仍相同则随机，并记录随机结果。
- 如果上一年该市场没有已选订单，则本年不产生市场龙头，直接按投入排序。

### 7.2.1A 订单生成规则

规则编号：`GAME-ORDER-GEN-001`

- 订单生成依据由当前订单模板决定：贵宾订单模板依据 `道具-订单推算（服务企业）.xlsx`，机场订单模板依据 `机场沙盘订单.xlsx`。
- 系统内置对应 Excel 的订单生成逻辑，不把 Excel 文件作为运行时随机引擎。
- 多年订单数量控制台是订单数量主来源，固定覆盖 `1年~8年 × 当前订单模板市场 × 当前订单模板订单类型`，并按 `1~3年 / 4~5年 / 6~8年` 三段展示。
- 市场预测由多年订单数量控制台和当前订单模板生成公式链生成，作为玩家端只读趋势展示；管理员配置的最终年份不裁剪市场预测三段展示。
- 玩家端市场预测图表按对应订单 Excel 的竖状柱状图口径展示：每个阶段下按市场分图，横轴为年份，柱子区分订单类型，并展示预测金额/订单量摘要。
- 每年开始前生成当年订单池。
- 管理员先配置当年市场开启状态；默认开启状态由订单模板定义，市场是否进入当年订单生成完全以管理员手动开启为准，控制台有数量但市场未开启时仍不生成订单、不进入开标。
- 管理员在多年订单数量控制台配置 `年份 + 市场 + 订单类型` 的订单卡片数量；全部模板均接受非负整数，不设置固定业务最大值；年度订单管理页只读取当年控制台数量，不再维护另一套订单数量。
- 已开启市场中，`0` 表示该标段未配置订单、不生成订单，也不进入该标段开标。
- 贵宾、生产和机场模板均取消每标段固定订单卡数量上限；超过原 Excel 静态卡片数时继续按同一公式逐张生成，允许参数重复但业务订单卡 ID 必须唯一。
- 贵宾模板商品均价、波动系数、最小订单数量、最大订单数量、账期范围等公式参数按 Excel 内置；首版不开放页面配置，但保存到生成批次参数快照。
- 贵宾模板每张启用订单卡按 Excel 公式随机生成订单数量和账期；订单金额按数量、均价、波动系数、最小/最大数量公式计算。
- 贵宾模板订单金额必须满足 `订单金额 = 数量 × 单价`。数量为整数，单价可以为小数；后端生成订单时自动校准有效单价，保证相乘后的订单金额为整数，不要求也不允许管理员逐单手工调整单价或金额。
- 机场模板每张启用订单卡按 Excel 公式随机生成架次、客座率、跑道要求、航线区域和账期；底层总收入按公式计算后四舍五入为整数 `M`，作为系统订单金额；单价保留 4 位小数，底层收入和底层吞吐量保存到扩展字段。
- 系统额外保存随机种子、公式版本、参数快照和订单明细，用于复盘和审计；随机种子不改变 Excel 业务规则。
- 预览批次可反复覆盖生成；如需调整数量，应先修改多年订单数量控制台再重新生成；确认后转为正式批次，不允许修改数量或重新生成。

### 7.2.1B 机场订单生成公式

规则编号：`GAME-ORDER-GEN-AIRPORT-001`

- 架次：`RANDBETWEEN(9000, 11000)`。
- 客座率：`RANDBETWEEN(60, 80)`。
- 吞吐量底层值：`160 × 架次 × 客座率 / 1000000`。
- 国内航线系数：`1`。
- 国际航线系数：`1.7`。
- 跑道系数：`4C = 1`，`4D = 2`，`4E = 2.4`，`4F = 3`。
- 单价：`客座率 / 200 × 0.012 × 航线系数 × 跑道系数`，页面展示 4 位小数。
- 底层总收入：`单价 × 架次`。
- 系统订单金额：底层总收入按 Excel 显示口径四舍五入为整数 `M`。
- 账期：`RANDBETWEEN(2, 4)` 季。
- 窄体订单跑道要求固定 `4C`。
- 宽体订单跑道要求按 Excel 随机 `4D / 4E / 4F`。
- 国内订单航线区域固定 `国内`。
- 国际订单航线区域按 Excel 随机 `亚太 / 欧非 / 美洲`。
- 页面不展示底层未取整收入；底层收入仅用于复盘。

### 7.2.2 标段释放与订单选择规则

规则编号：`GAME-ORDER-002`

- 每个 `市场 + 订单类型` 组合视为一个独立标段；标段数量由订单模板决定，贵宾模板每年最多 `16` 个标段，机场模板每年最多 `4` 个标段。
- 管理员开标前配置全年有效标段释放顺序；有效标段指已开启市场且订单数量大于 `0` 的标段，释放第一个有效标段后不允许调整。
- 开标前置条件为：所有未破产小组已提交当前订单模板下全部市场投入、当年订单池已确认、当年有效标段释放顺序已配置。
- 当前标段结束后，由管理员按预设顺序手动释放下一标段；系统不自动释放，管理员不能跳序。
- 未开启市场不进入标段释放；订单数量为 `0` 的已开启标段为未配置订单；订单数量大于 `0` 但所有未破产小组该标段投入均为 `0` 时，该标段才作为流程跳过。
- 任何小组当前标段投入为 `0` 时均无资格，市场龙头也不例外；龙头只影响有资格小组的基础顺序。
- 贵宾服务版和生产制造版按当前标段投入 `1~2 / 3~5 / 6~8 / >=9` 分别最多参加 `1 / 2 / 3 / 4` 轮；机场版暂时保持单轮。
- 每个标段只生成一次基础顺序，第二至第四轮只按资格过滤，不重新排序或随机；每个小组每轮最多选择 `1` 个订单。
- 释放标段后直接开始第一轮；后续有效轮次由管理员点击“开启下一轮”，空轮自动跳过。
- 任意轮次订单池提前选空时立即结束整个标段；全部有效轮次结束后的剩余订单标记为 `UNSELECTED_EXPIRED`，只保留审计记录。
- 订单被选择后锁定，不再对其他小组可选。
- 只有当前轮到的小组可以选择订单；后端必须校验当前轮次和订单可选状态。
- 玩家可放弃当前轮，确认后不可反悔但后续有资格轮次仍可参加；管理员可代为跳过当前轮长时间未操作的小组并填写原因，但不能代选订单。
- 玩家选单后不可撤销；首版管理员也不提供撤销或代选。
- 玩家端和管理员端通过 `3` 秒自动轮询同步订单状态，不做 WebSocket。
- 玩家端轮询应为静默刷新，不触发整页加载态，不重置页面滚动位置。

### 7.3 破产后的规则

规则编号：`GAME-003`

- 破产后后续年份不可编辑。
- 破产组不参与后续年份或后续未开始标段的订单竞标与选单。
- 历史数据保留。
- 管理员汇总页标记破产。
- 玩家仍可查看历史数据。
- 顺序生成后发生破产时，已选订单和已完成轮次保留；当前及未来未完成轮次自动失去资格，若其为当前小组则自动推进，其他小组不重排。

## 8. 异常解锁规则

规则编号：`ADMIN-001`

> 产品入口说明：异常解锁在管理员端并入 `回退与修正` 页面，作为轻量 `退回重提` 模式保留；它不依赖历史快照，适合本年内小范围修正。

- 仅管理员可执行。
- 仅允许在“下一年尚未开放前”解锁某组某年。
- 解锁后本年已锁定区域恢复可编辑。
- 若财报已提交，则财报失效。
- 若该年已进入汇总，则汇总快照撤回。
- 玩家修改后需重新提交经营阶段，必要时重新提交财报。

实现要求：

- 异常解锁是管理动作，不是普通状态。
- 退回重提不要求管理员填写原因；系统自动记录默认原因 `管理员退回重提`，并保留日志。
- 执行前必须生成回退前安全快照，便于审计和人工追溯。

## 9. 回退与修正规则

规则编号：`ADMIN-002`

### 9.1 公式口径

- 单组快照回退不改变经营页、财报页、订单生成或汇总排名公式。
- 回退只改变“哪些数据当前有效”，不重写公式链。
- 玩家重新提交后，仍按当前比赛版本绑定的字段模板、公式规则和流程规则重新计算。
- 订单交付自动写入销售收入属于系统扩展来源：不改 Excel 中“财报收入读取经营页销售收入”的公式链，但改变正式年份经营页销售收入的数据来源。

### 9.2 有效数据读取

- 经营页、财报页、汇总页、下一年结转只读取 `有效结果`。
- 目标节点之后的旧经营提交、财报提交、汇总快照和订单交付记录不删除，但应标记为失效或失效草稿；奖惩是独立管理员业务事件，普通退回重提继续有效，恢复快照时才按快照时点恢复有效状态。
- 失效草稿可作为玩家重新填写时的回填来源，不计入正式计算和排名。
- 销售收入只读取当前有效订单交付汇总；回退、恢复快照或旧草稿中的历史销售收入不直接进入当前有效经营、财报、汇总、排名或得分计算。

### 9.3 单组快照回退

- 首版只做单组、阶段级快照恢复，不做字段级回退。
- 可从后续年份回到早期年份的某个阶段，例如从 `5年` 回到 `3年 Q2`。
- 回退不改变全局当前开放年份。
- 回退执行前自动生成回退前安全快照。
- 连续回退允许；退回重提由系统自动记录默认原因，恢复快照仍需填写原因；每次都必须保留日志。
- 回退执行期间应短暂锁定目标组写操作；并发提交返回“状态已变化，请刷新页面”。
- `退回重提` 和 `恢复快照` 均恢复为待重提 / 失效草稿，不直接恢复旧结果有效性；区别仅在草稿来源：退回重提使用当前库中目标阶段数据，恢复快照使用历史快照载荷，二者都要求玩家重新提交后才重新生效。

### 9.4 订单边界

- 单组快照回退不回滚订单竞标结果。
- 已选订单保持归属，不释放回订单池。
- 不重算市场龙头。
- 不重排历史选单顺序。
- 不重新生成已确认订单池。
- 目标阶段及后续阶段的旧订单交付记录应保留为历史留痕 / 草稿参考，但不直接作为当前有效交付；对应订单恢复为待交付 / 可重新交付状态。
- 玩家重新推进到对应季度后，可以重新确认原订单交付，也可以改交其他仍归属本组的已选订单；系统只按重新确认后的当前有效交付记录生成销售收入。
- 未来年份已选订单保持归属，但在玩家重新推进到该年份前不进入有效经营结果。

### 9.5 奖惩、通知、汇总与破产

- 普通通知不回退。
- 普通退回重提保留全部有效奖励 / 罚款；恢复快照时按快照载荷恢复奖惩有效状态；单条奖惩纠错使用作废事件且保留审计信息。
- 目标节点之后的汇总结果失效；汇总页应显示 `待重提`，不计入排名。
- 已确认破产不可通过退回重提、恢复快照或作废奖惩恢复为 `NORMAL`。

### 9.5.1 年末奖惩重算

- 当前季度和 `YEAR_END` 的有效奖励 / 罚款分别按税前收入 / 支出口径汇总。
- `YEAR_END` 只进入年度奖罚总计、年末现金和财报结果，不反向改变 Q1 至 Q4 的季末现金核对值。
- 折现费用只汇总 Q1 至 Q4，不存在 `YEAR_END` 输入或存储字段。
- 奖惩变化后重新计算税前利润、所得税、净利润、所得税后现金、总资产、所有者权益和依赖这些字段的总监得分。
- 若所得税后现金小于 `0`，立即生成不计入正式财报与排名的破产快照，并进入不可撤销破产状态。

### 9.6 年度控制

- 只要存在任意未破产小组处于回退补提 / 待重提状态，管理员不能开放下一年。
- 必须等所有未破产小组完成当前开放年份要求，且不存在回退补提 / 待重提状态后，才能继续开放下一年。

## 10. 规则变更控制

### 10.1 可局部调整的内容

以下变化通常可局部调整，不必推翻全套设计：

- 字段显示名变化
- 页面标签变化
- 少量公式系数变化
- 个别非结构性衍生指标调整

### 10.2 必须回到需求确认的内容

以下变化一旦发生，必须同步回到需求确认流程：

- 阶段提交流程变化
- 订单竞标排序、市场龙头定义或标段释放顺序变化
- 订单交付处罚规则变化
- 破产规则变化
- 汇总口径变化
- 财报手工项边界变化
