## 2. 管理员端验收

- 赛前配置可选择 `机场沙盘版 V1`。
- 管理员顶部版本显示为 `机场沙盘版 V1`。
- 订单管理页的数量控制台只展示 `国内市场 / 国际市场` 和 `窄体 / 宽体`。
- 每个标段数量输入允许任意非负整数，不再设置 `15` 或 `28` 的固定业务上限。
- 国内市场默认开启，国际市场默认关闭，管理员可手动修改。
- 标段默认顺序为国内窄体、国内宽体、国际窄体、国际宽体，保存后可生成预览订单池。
- 订单池表显示机场扩展字段：航线区域、飞机类型、航线类型、跑道要求、架次、吞吐量、客座率。
- 订单金额展示为整数，单价展示最多 4 位小数。
- 生成选单顺序时，提示按当前模板的 `4` 项市场投入判断完整性。
- 2 年龙头测试中，国内市场按上年国内窄体 + 国内宽体已选订单金额判断，国际市场按上年国际窄体 + 国际宽体判断。

## 3. 玩家端验收

- 玩家订单页的市场投入表只展示 `4` 项投入。
- 未开启市场输入格置灰，并自动按 `0` 提交。
- 市场预测图按国内 / 国际分图展示窄体 / 宽体柱状数据。
- 订单卡展示机场字段，订单编号按标段从 `CARD-01` 起独立递增，不以 `CARD-28` 作为上限。
- 到当前小组时可以选择或放弃订单；未轮到的小组不能操作。
- 已被选择的订单在后续小组页面中置灰，不可重复选择。
- 机场版已选订单显示在待交付区域，但交付按钮不可用或提示当前模板暂不支持交付。
- 自动轮询不应把页面滚动到顶部。

## 4. 占位页验收

- 机场版玩家进入经营页时，显示 `机场沙盘版经营页待接入` 占位。
- 机场版玩家进入财报页时，显示 `机场沙盘版财报页待接入` 占位。
- 占位状态下不展示贵宾版或生产版经营 / 财报字段。
- 占位状态下不允许保存或提交经营 / 财报数据。
- 订单页仍可独立联调。

## 5. 回归验收

- 贵宾服务版仍为本地 / 区域 / 全国 / 全球 × 代办过检 / 两舱贵宾 / 商务贵宾 / 会员定制。
- 生产制造版订单页仍沿用贵宾订单模板。
- 贵宾 / 生产订单数量同样取消固定业务上限；机场版本次仍保持单轮选单，不套用贵宾 / 生产的四轮资格规则。
- 贵宾 / 生产订单交付仍可按原规则使用。
- 原订单开标测试停点 `seed-order-scenario -confirm-reset` 仍可跑通。

## 6. 已知边界

- 本轮不支持上传机场 Excel 自动抽公式。
- 本轮不支持管理员在线编辑订单公式。
- 本轮不支持管理员新增 / 删除市场或订单类型。
- 本轮不接入机场经营页和财报页完整模板。
- 本轮不做机场完整经营闭环和最终排名。
