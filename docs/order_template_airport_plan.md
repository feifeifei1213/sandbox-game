# 订单模块可插拔与机场订单模板方案

> 更新日期：2026-06-12
> 适用范围：`I9 订单模块可插拔与机场订单模板`

## 1. 背景

当前订单模块已实现贵宾服务订单主链路，订单结构为 `本地 / 区域 / 全国 / 全球` 四个市场乘以 `代办过检 / 两舱贵宾 / 商务贵宾 / 会员定制` 四类订单，每年最多 `16` 个标段。

新收到的 `机场沙盘订单.xlsx` 是机场沙盘版订单生成器。该工作簿不是现有贵宾订单的简单改名，而是新的订单模板：

- 市场维度变为 `国内市场 / 国际市场`。
- 订单类型变为 `窄体 / 宽体`。
- 每年最多 `4` 个标段。
- 每个标段最多 `28` 张订单卡。
- 订单卡字段包含航线区域、飞机类型、航线类型、跑道要求、架次、吞吐量、客座率、总收入、单价、账期等。

因此下一阶段目标不是把现有订单页硬改为机场订单，而是先把订单模块升级为可插拔订单模板，再接入机场订单模板。

## 2. 总体目标

新增 `I9` 阶段，目标为：

1. 将订单模块从固定 `VIP_ORDER_TEMPLATE_V1` 改造为按当前比赛订单模板驱动。
2. 保持贵宾服务版、生产制造版现有订单行为不变。
3. 新增 `AIRPORT_V1` 机场沙盘版版本包。
4. 新增 `AIRPORT_ORDER_TEMPLATE_V1` 机场订单模板。
5. 机场版经营页和财报页 Excel 尚未提供前，不接入贵宾版或生产版经营 / 财报模板，先显示占位页，不允许填写和提交。
6. 机场版支持订单模块独立联调，可测试订单数量配置、订单池生成、市场投入、开标、选单、放弃、锁定和市场龙头。

## 3. 版本包与模板关系

### 3.1 已有版本

`VIP_SERVICE_V1`：

- 经营页模板：`VIP_OPERATING_TEMPLATE_V1`
- 财报页模板：`VIP_REPORT_TEMPLATE_V1`
- 订单模板：`VIP_ORDER_TEMPLATE_V1`
- 公式规则：`COMMON_FORMULA_V1`
- 流程规则：`COMMON_PROCESS_V1`

`PRODUCTION_V1`：

- 经营页模板：`PRODUCTION_OPERATING_TEMPLATE_V1`
- 财报页模板：`PRODUCTION_REPORT_TEMPLATE_V1`
- 订单模板：暂用 `VIP_ORDER_TEMPLATE_V1`
- 公式规则：`COMMON_FORMULA_V1`
- 流程规则：`COMMON_PROCESS_V1`

### 3.2 新增机场版本

`AIRPORT_V1`：

- 版本名称：`机场沙盘版 V1`
- 经营页模板：`PENDING_OPERATING_TEMPLATE`
- 财报页模板：`PENDING_REPORT_TEMPLATE`
- 订单模板：`AIRPORT_ORDER_TEMPLATE_V1`
- 订单生成公式：`AIRPORT_ORDER_FORMULA_V1`
- 流程规则：暂用 `COMMON_PROCESS_V1`

机场经营页 / 财报页模板待后续 Excel 给到后新增，不用贵宾版或生产版临时替代，避免字段和公式口径错乱。

## 4. 订单模板能力边界

订单模板应定义：

- 市场列表
- 订单类型列表
- 每标段最大订单卡数量
- 默认市场开启状态
- 默认标段释放顺序
- 市场预测展示维度
- 订单池字段定义
- 订单金额、数量、单价、账期展示格式
- 订单生成公式版本

公共订单流程继续复用：

- 多年订单数量控制台
- 市场开启 / 关闭
- 单市场投入上限
- 订单池预览生成
- 订单池确认
- 市场投入提交
- 选单顺序生成
- 标段释放
- 玩家选择 / 放弃订单
- 订单锁定
- 市场龙头计算
- 自动轮询与状态展示

## 5. 机场订单模板规则

### 5.1 市场与订单类型

机场版市场：

- `DOMESTIC`：国内市场
- `INTERNATIONAL`：国际市场

机场版订单类型：

- `NARROW_BODY`：窄体
- `WIDE_BODY`：宽体

每个 `市场 + 订单类型` 为一个独立标段，每年最多 `4` 个标段。

默认释放顺序：

1. 国内市场 - 窄体
2. 国内市场 - 宽体
3. 国际市场 - 窄体
4. 国际市场 - 宽体

管理员开标前可调整释放顺序；开标过程中不允许修改。

### 5.2 市场开启与投入上限

- 国内市场默认开启。
- 国际市场默认关闭。
- 管理员可在订单池确认前、且本年尚无任何小组提交市场投入前，手动开启或关闭任一市场。
- 若国内市场被管理员关闭，则国内窄体、国内宽体均不生成订单、不进入开标，玩家端对应投入自动按 `0` 提交。
- 若国际市场关闭，同理国际窄体、国际宽体自动按 `0` 提交。
- 市场投入上限按市场合计控制，不按标段控制。
- 国内市场投入上限 = 国内窄体投入 + 国内宽体投入的上限。
- 国际市场投入上限 = 国际窄体投入 + 国际宽体投入的上限。
- 空值表示无上限。

### 5.3 多年订单数量控制台与预测

- 机场版同样固定覆盖 `1年 ~ 8年`，不受管理员最终年份裁剪。
- 控制台结构为 `1年~8年 × 2市场 × 2订单类型`。
- 默认数量全部为 `0`，不自动带入 Excel 示例数量，由管理员手动配置。
- 每个标段订单数量范围为 `0 ~ 28`。
- 市场预测继续按 `1~3年 / 4~5年 / 6~8年` 三段展示。
- 预测图按市场分图，国内市场展示窄体 / 宽体收入与订单数量，国际市场同理。
- 预测和正式订单池使用同一套机场订单生成公式，但正式订单池仍只在每年开始前生成当年订单。

### 5.4 订单字段

机场订单卡展示字段：

- 订单编号
- 航线区域
- 飞机类型
- 航线类型
- 跑道要求
- 架次
- 吞吐量
- 客座率
- 总收入
- 单价
- 账期

订单编号沿用 `CARD-01 ~ CARD-28`，每个标段内独立编号。

页面不展示底层未取整收入，只展示按 Excel 显示口径处理后的整数总收入。

### 5.5 机场订单生成公式

机场订单生成依据为 `机场沙盘订单.xlsx`，系统内置公式，不把 Excel 文件作为运行时随机引擎。

公式口径：

- 架次：`RANDBETWEEN(9000, 11000)`
- 客座率：`RANDBETWEEN(60, 80)`
- 吞吐量底层值：`160 × 架次 × 客座率 / 1000000`
- 国内航线系数：`1`
- 国际航线系数：`1.7`
- 跑道系数：
  - `4C`：`1`
  - `4D`：`2`
  - `4E`：`2.4`
  - `4F`：`3`
- 单价：`客座率 / 200 × 0.012 × 航线系数 × 跑道系数`
- 底层总收入：`单价 × 架次`
- 订单金额：底层总收入按 Excel 显示口径四舍五入为整数 `M`
- 账期：`RANDBETWEEN(2, 4)` 季

字段显示口径：

- `order_amount`：保存四舍五入后的整数总收入，参与选单、交付、经营页联动和市场龙头统计。
- `unit_price`：保存并展示 4 位小数。
- `order_quantity`：保存架次。
- `吞吐量`：按 Excel 显示口径取整展示；底层值保存到扩展字段。
- `客座率`：保存整数，页面显示为百分比。
- 窄体订单跑道要求固定 `4C`。
- 宽体订单跑道要求按 Excel 随机 `4D / 4E / 4F`。
- 国内订单航线区域固定 `国内`。
- 国际订单航线区域按 Excel 随机 `亚太 / 欧非 / 美洲`。

### 5.6 数据存储建议

订单主表继续保存所有模板通用、且参与流程的字段：

- 年份
- 市场
- 订单类型
- 标段编码
- 订单编号
- 订单金额
- 主数量
- 单价
- 账期
- 状态
- 选中小组
- 生成批次

新增 `order_payload_json` 保存模板专属字段。机场版建议写入：

```json
{
  "routeRegion": "国内",
  "aircraftType": "窄体",
  "routeType": "国内",
  "runwayRequirement": "4C",
  "flightCount": 9310,
  "throughput": 97,
  "rawThroughput": 96.824,
  "loadFactor": 65,
  "rawRevenue": 36.309,
  "displayRevenue": 36
}
```

采用公共字段 + 扩展字段的原因：

- 贵宾订单、机场订单和后续订单模板字段差异较大。
- 订单主表应保持流程字段稳定，避免每新增一个模板就增加大量只对某模板有效的列。
- 前端仍可按模板字段定义展示扩展字段，不影响玩家查看。

## 6. 市场龙头与排序

机场版复用现有排序规则：

- `1年`：按当前标段市场投入从高到低排序；相同则随机。
- `2年` 起：该市场上一年市场龙头优先，其余小组按当前标段投入排序。
- 国内市场龙头 = 上一年国内窄体 + 国内宽体已选订单金额合计最高的小组。
- 国际市场龙头 = 上一年国际窄体 + 国际宽体已选订单金额合计最高的小组。
- 每个市场每年唯一市场龙头；并列最高时随机确定一个并记录随机结果。
- 市场龙头只在对应市场生效，不跨市场。
- 市场龙头即使当前标段投入为 `0`，仍可在该市场优先选单。
- 非龙头小组当前标段投入为 `0` 时，不参与该标段选单。
- 非龙头小组投入相同，按上一年该市场订单金额合计从高到低排序；仍相同则随机。

市场龙头按已选订单金额统计，不要求订单已交付。

## 7. 经营页与财报页边界

机场经营页和财报页 Excel 尚未提供前：

- 管理员可在赛前选择 `机场沙盘版 V1`。
- 玩家订单页可完成机场订单模块独立联调。
- 玩家进入经营页 / 财报页时显示占位说明：`机场沙盘版经营页 / 财报页待接入，当前仅支持订单模块联调`。
- 占位页不允许填写和提交。
- 机场版订单交付按钮保留展示，但置灰不可点击。
- 机场版暂不支持完整比赛经营闭环、完整年度结转和最终排名。

## 8. 前端页面改造原则

管理员订单页和玩家订单页沿用现有页面结构，不重做流程：

- 管理员端继续使用数量控制、市场设置、标段顺序、订单池、竞标控制等模块。
- 玩家端继续使用市场预测、市场投入、标段选单、订单池、已选订单等模块。

需要改造的是模板相关部分：

- 市场列表从当前订单模板读取。
- 订单类型列表从当前订单模板读取。
- 每标段最大订单数从当前订单模板读取。
- 默认开启市场从当前订单模板读取。
- 默认释放顺序从当前订单模板读取。
- 预测图维度从当前订单模板读取。
- 订单卡字段按当前订单模板字段定义渲染。

不能把现有前端硬编码直接改成机场版，否则会影响贵宾版和生产制造版。

## 9. 测试与造数

需要新增机场订单专项造数能力：

1. 初始化机场版并停在 `1年订单配置前`，用于测试管理员从空控制台开始配置、生成订单池、开标。
2. 造出 `1年已选订单历史` 并停在 `2年订单配置前`，用于测试国内 / 国际市场龙头和 `2年` 排序。

该能力只用于测试库或演示库，不改变正式比赛规则。

## 10. 不纳入本轮

- 上传机场 Excel 自动抽公式。
- 管理员在线编辑机场订单公式。
- 管理员新增 / 删除市场或订单类型。
- 机场经营页和财报页正式模板。
- 机场完整经营闭环和最终排名。
- 订单选择撤销。
- 未交付处罚自动计算。
