# 管理员订单池按小组查看已选订单开发说明

> 更新时间：2026-07-28
> 任务编号：I13-11
> 适用范围：管理员端订单管理页「订单池」查看区
> 关联模块：订单池查询、订单多轮选单结果查看、管理员订单页筛选体验

## 1. 背景

管理员端订单池页面当前可以按年份、市场和订单类型查看订单池记录。多轮选单完成后，管理员虽然能在标段顺序区看到当前标段和轮次状态，但缺少一个直接按小组查看「该小组已经拿到哪些订单」的入口。

用户确认本次目标不是分析全部无效订单，也不是新增独立小组订单页，而是在订单池页面现有筛选区增加小组筛选，让管理员快速查看某个小组已选中的订单。

## 2. 目标

1. 在管理员端订单池查看区新增「小组」筛选。
2. 支持按具体小组查看该小组已经拿到的订单。
3. 支持查看全部小组已经拿到的订单。
4. 保留现有按年份、市场、订单类型查看订单池的能力。
5. 市场、订单类型和小组筛选可以叠加使用。

## 3. 非目标

本次不做以下能力：

- 不新增独立「小组订单」页面。
- 不修改玩家端订单页。
- 不修改订单选择、放弃、跳过、交付、经营页联动、市场龙头或多轮推进逻辑。
- 不新增未选订单、过期订单、无效订单的专门筛选入口。
- 不修改订单池生成、确认、锁定和历史年份保护规则。
- 不做分页、导出或统计图表。

## 4. 业务口径

小组筛选只用于查看「已被小组选中」的订单。

筛选项建议为：

| 小组筛选 | 查询结果 |
|---|---|
| 全部订单 | 保持原有订单池查看能力，展示当前年份、市场、订单类型条件下的全部订单 |
| 全部已选小组 | 只展示 `selected_group_id IS NOT NULL` 的订单 |
| 第 N 组 | 只展示 `selected_group_id = N` 的订单 |

说明：

- 「第 N 组」下不会展示未选订单、过期未选订单或其他无小组归属的订单。
- 「全部已选小组」用于快速查看所有已被小组拿走的订单。
- 「全部订单」用于保留管理员在生成预览池、确认订单池前后的原有核对能力。

## 5. 前端设计

### 5.1 页面位置

在管理员订单页「订单池查看」筛选区中，现有筛选为：

```text
市场
订单类型
```

新增为：

```text
市场
订单类型
小组
```

### 5.2 小组下拉选项

下拉选项：

```text
全部订单
全部已选小组
第 1 组
第 2 组
第 3 组
...
```

小组名称优先使用后端返回的 `groupName`；若为空，则按 `selectedGroupId` 显示为 `第 N 组`。

### 5.3 表格显示

订单池表格继续使用原有列结构。

「选中组」列显示优化为：

- 有小组归属：显示小组名称，例如 `第 1 组`
- 无小组归属：显示 `--`

当小组筛选后无记录时，空态文案建议：

```text
当前筛选下没有小组已选订单记录。
```

## 6. 后端设计

### 6.1 查询参数

管理员订单池查询接口保持原地址：

```text
GET /api/v1/sandbox-game/admin-order/get-order-pool
```

新增可选参数：

| 参数 | 类型 | 含义 |
|---|---|---|
| `selectedOnly` | bool | 是否只查看已被小组选中的订单 |
| `selectedGroupId` | int64 | 指定小组 ID；传入后天然只查看该小组选中的订单 |

保留原有参数：

| 参数 | 类型 | 含义 |
|---|---|---|
| `yearNo` | int | 年份 |
| `marketCode` | string | 市场筛选，`ALL` 或空表示全部市场 |
| `orderType` | string | 订单类型筛选，`ALL` 或空表示全部类型 |

### 6.2 查询规则

后端查询条件：

```text
year_no = ?
```

若选择市场：

```text
AND market_code = ?
```

若选择订单类型：

```text
AND order_type = ?
```

若 `selectedOnly=true`：

```text
AND selected_group_id IS NOT NULL
```

若传入 `selectedGroupId`：

```text
AND selected_group_id = ?
```

若 `selectedGroupId` 指向不存在的小组，接口返回参数错误，避免页面出现无法解释的空结果。

### 6.3 返回字段

订单池单条记录建议新增：

| 字段 | 含义 |
|---|---|
| `selectedGroupName` | 订单被选中小组的显示名称，无归属时为空 |

订单池结果建议新增：

| 字段 | 含义 |
|---|---|
| `selectedOnly` | 当前是否只看已选订单 |
| `selectedGroupId` | 当前指定小组筛选 |
| `groupOptions` | 当前比赛小组下拉选项 |

## 7. 验收标准

1. 管理员进入订单池页面，筛选区出现「小组」下拉框。
2. 默认「全部订单」时，订单池仍按原有逻辑展示全部订单。
3. 选择「全部已选小组」后，只展示已被任意小组选中的订单。
4. 选择「第 1 组」后，只展示第 1 组拿到的订单。
5. 市场、订单类型、小组三个筛选可以叠加使用。
6. 未选订单和 `UNSELECTED_EXPIRED` 且没有小组归属的订单不会出现在小组筛选结果中。
7. 表格「选中组」列优先显示小组名称，不再只显示 `组ID N`。
8. 不影响订单池生成、确认、多轮选单、开启下一轮、交付和市场龙头。
