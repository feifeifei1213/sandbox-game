# 赛前配置中心与业务显示字典验收清单

> 更新日期：2026-06-03  
> 适用范围：`I8-01 ~ I8-08`，覆盖赛前配置中心、沙盘版本包选择、业务显示字典方案、当前比赛字典快照、修改日志和前端静默同步。

## 1. 验收前提

- 后端已启动：`go run ./cmd/server -config configs/local.yaml`
- 前端已启动：在 `frontend/` 执行 `npm run dev`
- 管理员账号可登录：`admin / 123456`
- 当前联调库不是正式比赛库
- 若要从最初状态验收，先执行赛前重置命令，使系统停在“尚未初始化比赛”

## 2. 赛前配置验收

1. 管理员登录未初始化环境。  
   期望：默认进入 `赛前配置` 页面，页面集中展示基础信息、版本包、业务显示字典、初始基线入口和确认初始化。

2. 切换沙盘版本包。  
   期望：页面展示对应版本名称、字段模板、公式版本和流程规则；业务显示字典显示该版本包的默认名称。

3. 修改业务显示名称。  
   期望：只允许修改显示名；字段编码不展示给普通管理员视角；显示名为空时初始化或保存会被拦截。

4. 保存字典方案。  
   期望：可将当前显示名称另存为自定义方案；方案出现在当前版本包的方案列表中。

5. 选择字典方案。  
   期望：下拉选择自定义方案后，编辑器实际加载该方案明细，而不只是显示方案名。

6. 更新和删除字典方案。  
   期望：可用当前编辑内容覆盖自定义方案；可删除自定义方案；删除方案不影响当前编辑以外的比赛快照。

7. 确认初始化比赛。  
   期望：系统生成小组、账号、年份状态，并将当前显示名称写入当前比赛字典快照；初始化结果返回 `dictionaryRevision = 1`。

## 3. 初始化后验收

1. 再次进入 `赛前配置`。  
   期望：页面变为当前比赛配置展示，版本包、公式版本和流程规则只读；仍可进入初始基线页；最终年份提示在年度控制页维护。

2. 解锁修改当前比赛显示名称。  
   期望：点击 `解锁修改显示名称` 后可编辑当前比赛字典；保存后 `dictionaryRevision` 自增，页面提示成功。

3. 应用字典方案到当前比赛。  
   期望：只能应用同版本包方案；前端确认框展示变更数量和部分变更明细；确认后整体覆盖当前比赛显示名称并写日志。

4. 恢复默认显示名称。  
   期望：前端确认框展示变更数量和部分变更明细；确认后恢复当前版本包默认名称并写日志。

5. 查看修改日志。  
   期望：日志展示初始化、保存方案、删除方案、修改当前名称、应用方案、恢复默认等记录，包含操作人、时间、revision 和变更摘要。

6. 跨版本方案限制。  
   期望：生产版方案不能应用到贵宾服务版当前比赛，服务端返回跨版本错误。

## 4. 玩家端和业务页面验收

1. 玩家经营页。  
   期望：经营页业务字段名称按当前比赛字典显示；保存草稿、提交阶段和计算 payload 仍使用稳定字段，不因显示名称变化而改变。

2. 玩家财报页。  
   期望：财报页字段名称和必填提示按当前比赛字典显示；资产负债校验逻辑不受显示名变化影响。

3. 玩家订单页。  
   期望：市场名称、订单类型名称、市场预测和订单列表按当前比赛字典显示；页面自动轮询不会把滚动位置重置到顶部。

4. 管理员初始基线页。  
   期望：初始基线字段显示名称按当前比赛字典显示；提交 payload 仍使用稳定字段。

5. 管理员订单页。  
   期望：市场名称、订单类型名称、订单数量控制台、市场预测、释放顺序、订单池和选单顺序按当前比赛字典显示。

6. 不替换系统文案。  
   期望：菜单、按钮、错误提示、Q1/Q2/Q3/Q4、年末、财报、普通通知自由文本、回退流程状态等系统文案不被业务显示字典替换。

## 5. 静默同步验收

1. 玩家停留在经营页或订单页，管理员修改当前比赛显示名称。  
   期望：玩家端通过轻量 `dictionaryRevision` 检查同步新名称；不弹窗、不清空草稿、不改变当前页签、不重新加载业务数据、不滚动到顶部。

2. 管理员订单页或初始基线页停留时修改字典。  
   期望：页面名称静默更新；输入框内容、筛选条件和当前操作状态不被重置。
