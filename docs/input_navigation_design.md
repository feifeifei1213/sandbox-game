# 玩家端输入导航与输入态优化开发说明

> 更新日期：2026-07-24
> 状态：已按首版口径完成开发，待页面人工复测
> 适用范围：玩家端经营页、玩家端财报页、玩家端订单页市场投入；管理员端数字输入的回车结束输入态。
> 文档定位：本文件只定义前端输入交互优化的开发口径，不改变经营、财报、订单、保存草稿、提交或后端校验规则。

## 1. 背景

当前玩家端和管理员端的数字输入多数已经通过 `@input` 或 `v-model` 实时写入前端草稿状态，但用户在输入完成后仍会看到光标停留在输入框内，需要手动点击空白区域，输入态才会结束。

本次优化解决两个体验问题：

1. 输入完成后可以通过键盘结束输入态，不必再点击页面空白处。
2. 玩家端连续录入时，按回车可以跳到下一个可编辑输入格，并通过焦点高亮明确当前正在填写的位置。

本次优化不解决以下问题：

- 不修改保存草稿频率。
- 不把回车做成保存。
- 不把回车做成提交。
- 不引入完整 Excel 编辑器能力。
- 不改变任何后端接口、校验或计算规则。

## 2. 已确认口径

### 2.1 玩家端

玩家端做“回车跳下一格 + 当前格高亮”。

规则如下：

- 玩家在数字输入格中输入后，按 `Enter`。
- 当前输入格结束输入态。
- 焦点跳到当前页面 / 当前模块里的下一个可编辑数字输入框。
- 跳转时跳过禁用、只读、隐藏、未开放、不可编辑的输入框。
- 如果当前已经是最后一个可编辑输入框，则只结束输入态，不循环回第一个。
- 回车不触发保存草稿。
- 回车不触发阶段提交、财报提交、市场投入提交、选单或交付动作。
- 当前正在输入的格子需要高亮显示。

### 2.2 管理员端

管理员端只做“回车结束输入态”。

说明：本节记录的是 `I14` 首版已完成口径。用户于 2026-07-24 进一步确认管理员端部分连续录入区域需要做专项增强，后续以 `docs/admin_input_navigation_design.md` 为准；该增强只覆盖赛前配置字典、初始基线、订单数量控制和释放顺序，不改变本文关于保存、提交、按钮、下拉框、搜索框和多行文本框不被 `Enter` 接管的原则。

规则如下：

- 管理员在数字输入框中输入后，按 `Enter`。
- 当前输入框结束输入态，效果等同于点击页面空白处。
- 不跳到下一个输入框。
- 不做当前格高亮。
- 不触发表单提交、保存、预览、发送或其他按钮动作。

原因：

- 管理员端更多是配置表单、动作按钮和状态控制，不是玩家端 Excel 风格连续填表。
- 管理员页面包含原因说明、预览、确认、切换等动作，若统一做跳格，容易让回车语义混乱。

## 3. 范围拆分

### 3.1 玩家端首版覆盖页面

| 页面 | 范围 | Enter 行为 | 当前格高亮 | 说明 |
|---|---|---|---|---|
| 玩家经营页 | 经营表格内可编辑数字输入格 | 跳到下一个可编辑数字输入格 | 做 | 最核心录入场景，优先实现 |
| 玩家财报页 | 手工数字输入格 | 跳到下一个可编辑数字输入格 | 做 | 所得税税率下拉不参与跳转 |
| 玩家订单页 | 市场投入矩阵数字输入格 | 跳到下一个可编辑数字输入格 | 做 | 仅市场投入参与，订单卡片和交付区不参与 |

### 3.2 管理员端首版覆盖页面

管理员端只对数字输入框做 `Enter` 结束输入态。建议覆盖以下已有数字录入位置：

| 页面 | 输入项 | Enter 行为 | 当前格高亮 | 跳下一格 |
|---|---|---|---|---|
| 管理员初始基线页 | 初始基线数字字段 | 结束输入态 | 不做 | 不做 |
| 管理员订单配置页 | 多年订单数量控制台、单市场投入上限、释放顺序 | 结束输入态 | 不做 | 不做 |
| 管理员通知与奖惩页 | 奖励 / 罚款金额 | 结束输入态 | 不做 | 不做 |
| 管理员年度控制页 | 最终年份 | 结束输入态 | 不做 | 不做 |
| 管理员赛前配置页 | 小组数量 | 结束输入态 | 不做 | 不做 |
| 管理员回退与修正页 | 年份等数字筛选或表单字段 | 结束输入态 | 不做 | 不做 |

## 4. 不参与跳转或特殊处理的控件

本次不接管以下控件：

- `textarea`
  - 回车保留换行能力。
  - 例如普通通知内容、奖惩原因、作废原因、快照恢复原因。
- `select`
  - 下拉框保留浏览器和组件自身键盘行为。
  - 例如财报所得税税率、年份选择、市场筛选、状态筛选。
- `button`
  - 不通过回车跳转到按钮。
  - 不通过回车触发保存、提交、选择订单或交付订单。
- `checkbox`
  - 不参与跳转。
- 搜索框和确认文本框
  - 不参与玩家端连续录入跳转。
  - 管理员端如为普通文本输入，首版不接管；仅明确数字输入接管回车结束输入态。
- 只读计算值、锁定格、隐藏格
  - 不参与跳转。

## 5. 玩家端跳转规则

### 5.1 通用规则

玩家端跳转采用“当前模块内，从左到右、从上到下”的页面顺序。

技术上可按 DOM 顺序实现，但必须通过显式范围和显式标记控制跳转对象：

- 跳转范围使用类似 `data-enter-nav-scope` 的容器标记。
- 参与跳转的输入框使用类似 `data-enter-nav` 的输入标记。
- 查询下一个输入框时，只在当前 `data-enter-nav-scope` 内寻找。
- 输入框必须同时满足以下条件才可参与跳转：
  - 是 `HTMLInputElement`。
  - 未禁用。
  - 非只读。
  - 可见。
  - 当前可聚焦。
  - 带有参与跳转标记。

### 5.2 玩家经营页

玩家经营页跳转只在经营主表内发生。

规则：

- 只跳当前阶段可编辑的输入格。
- 未开放阶段输入格自动跳过。
- 只读联动格自动跳过。
- 管理员下发奖惩只读展示格自动跳过。
- 失效草稿中不可编辑的格子自动跳过。
- 当前格存在整数校验错误时仍允许跳走，错误样式保留。

示例：

- Q1 阶段：按回车从当前 Q1 可编辑格跳到下一个 Q1 可编辑格，Q2/Q3/Q4 锁定格跳过。
- 年末未开放：年末输入格不参与跳转。
- 市场竞标已由订单模块联动为只读时，对应输入格不参与跳转。

### 5.3 玩家财报页

财报页只让手工数字输入参与跳转。

参与跳转：

- 在制品
- 成品
- 材料
- 企业认证得分
- 生产人力得分
- 关账速度得分

不参与跳转：

- 所得税税率下拉框
- 自动计算值
- 平衡校验结果
- 保存 / 提交按钮

### 5.4 玩家订单页

订单页只让市场投入矩阵参与跳转。

参与跳转：

- 当前年份市场投入区域中的可编辑数字输入框。

不参与跳转：

- 市场预测展示。
- 订单卡片。
- 本组已选订单。
- 交付面板。
- 选择订单、放弃本轮、交付订单等按钮。

规则：

- 按市场投入矩阵的页面顺序跳转。
- 关闭市场的投入格跳过。
- 已提交投入后变成不可编辑的格子跳过。
- 未到市场投入阶段或不可提交时，输入格不参与跳转。

## 6. 当前格高亮规则

当前格高亮只在玩家端做。

### 6.1 颜色语义

页面颜色语义应保持分层：

| 样式语义 | 建议表达 |
|---|---|
| 可编辑 | 原绿色底色保留 |
| 当前正在输入 | 叠加蓝色描边 / 浅蓝光晕 |
| 锁定 | 原灰色锁定态保留 |
| 计算 / 提示 | 原黄色或计算态保留 |
| 校验错误 | 原红色错误态保留，同时可叠加焦点描边 |
| 失效草稿 / 回退提示 | 原橙色或提示态保留，同时可叠加焦点描边 |

### 6.2 为什么不直接把当前格改成更绿

绿色已经表示“这个格子可编辑”。当前输入格表示“用户现在正在填写哪个格子”。这两个语义不同，如果都只靠绿色表达，在经营页大量绿色格子的情况下，玩家仍然不容易定位当前焦点。

因此当前格高亮应叠加在原业务底色上，而不是替换原底色。

推荐口径：

```text
绿色 = 可编辑
蓝色描边 / 浅蓝光晕 = 当前正在输入
灰色 = 锁定
黄色 = 计算 / 提示
红色 = 错误
```

### 6.3 推荐 CSS 思路

优先使用 `:focus-within`，避免引入额外前端状态。

示例：

```css
.input-cell:focus-within,
.manual-cell:focus-within,
.investment-cell:focus-within {
  box-shadow: inset 0 0 0 2px #2563eb, 0 0 0 2px rgba(37, 99, 235, 0.12);
}
```

注意：

- 不要用焦点样式覆盖红色错误底色。
- 不要用焦点样式覆盖灰色锁定语义。
- 焦点样式应只在玩家端录入区域启用。

## 7. 技术实现建议

### 7.1 新增通用工具

建议新增：

```text
frontend/src/utils/input-navigation.ts
```

建议包含两个函数：

```ts
confirmInputOnEnter(event: KeyboardEvent): void
focusNextInputOnEnter(event: KeyboardEvent): void
```

语义：

- `confirmInputOnEnter`
  - 用于管理员端数字输入。
  - `Enter` 时只结束当前输入态。
- `focusNextInputOnEnter`
  - 用于玩家端连续录入。
  - `Enter` 时寻找同范围内下一个可编辑输入框；找不到则结束当前输入态。

### 7.2 通用处理要求

两个函数都应满足：

- 如果 `event.isComposing === true`，直接返回，避免中文输入法组合态误触发。
- 调用 `event.preventDefault()`，避免浏览器表单默认提交或按钮触发。
- 不调用任何保存、提交、预览、发送、选单、交付相关方法。
- 只处理 `HTMLInputElement`，不处理 `textarea`、`select`、`button`。

### 7.3 玩家端跳转伪代码

```ts
function focusNextInputOnEnter(event: KeyboardEvent) {
  if (event.isComposing) return

  const current = event.target
  if (!(current instanceof HTMLInputElement)) return

  event.preventDefault()

  const scope = current.closest('[data-enter-nav-scope]')
  if (!scope) {
    current.blur()
    return
  }

  const inputs = Array.from(scope.querySelectorAll<HTMLInputElement>('input[data-enter-nav]'))
    .filter(isFocusableInput)

  const currentIndex = inputs.indexOf(current)
  const next = inputs[currentIndex + 1]
  if (!next) {
    current.blur()
    return
  }

  next.focus()
  try {
    next.select()
  } catch {
    // 部分输入类型可能不支持 select，忽略即可。
  }
}
```

`isFocusableInput` 至少判断：

- 非 `disabled`
- 非 `readOnly`
- 不是 `type="hidden"`
- 可见
- 在当前文档中
- 可聚焦

### 7.4 页面接入建议

玩家经营页：

- 在经营主表容器增加 `data-enter-nav-scope`。
- 给参与跳转的数字输入框增加 `data-enter-nav`。
- 绑定 `@keydown.enter="focusNextInputOnEnter"`。
- 增加玩家端焦点高亮样式。

玩家财报页：

- 在财报主表容器增加 `data-enter-nav-scope`。
- 仅给 `manual-number` 的输入框增加 `data-enter-nav`。
- 所得税税率 `select` 不参与。
- 增加玩家端焦点高亮样式。

玩家订单页：

- 在市场投入矩阵容器增加 `data-enter-nav-scope`。
- 仅给市场投入数字输入框增加 `data-enter-nav`。
- 订单卡片、按钮和交付区不参与。
- 增加市场投入格焦点高亮样式。

管理员端：

- 只给明确的数字输入框绑定 `@keydown.enter="confirmInputOnEnter"`。
- 不增加 `data-enter-nav-scope`。
- 不增加焦点高亮样式。

## 8. 验收清单

### 8.1 玩家经营页

- Q1 阶段输入 `10` 后按 `Enter`，跳到下一个 Q1 可编辑输入格。
- Q2/Q3/Q4 未开放时，按 `Enter` 不会跳到锁定格。
- 年末未开放时，按 `Enter` 不会跳到年末输入格。
- 当前输入格有蓝色描边 / 浅蓝光晕。
- 输入小数后按 `Enter` 可以跳走，原格保留错误样式。
- 最后一个可编辑输入格按 `Enter` 只结束输入态，不循环回开头。
- 按 `Enter` 不保存草稿。
- 按 `Enter` 不提交阶段。

### 8.2 玩家财报页

- 在制品输入后按 `Enter`，跳到成品。
- 成品输入后按 `Enter`，跳到材料。
- 所得税税率下拉框不参与跳转。
- 企业认证得分、生产人力得分、关账速度得分可按页面顺序跳转。
- 当前输入格有焦点高亮。
- 按 `Enter` 不提交财报。

### 8.3 玩家订单页

- 市场投入输入后按 `Enter`，跳到下一个可编辑投入格。
- 关闭市场的投入格被跳过。
- 已提交投入后不可编辑的投入格被跳过。
- 当前投入格有焦点高亮。
- 按 `Enter` 不提交市场投入。
- 按 `Enter` 不选择订单、不交付订单。

### 8.4 管理员端

- 数字输入框输入后按 `Enter`，输入框失焦。
- 按 `Enter` 不跳到下一个输入框。
- 按 `Enter` 不触发保存、提交、预览、发送或确认按钮。
- 管理员端不出现玩家端当前格高亮样式。

## 9. 后续可选增强

以下能力不进入首版：

- `Shift + Enter` 跳到上一个可编辑输入格。
- `Tab / Shift + Tab` 自定义跳转。
- 方向键导航。
- 最后一格循环回第一个。
- 管理员订单数量控制台 Excel 化连续跳格（已转入 `docs/admin_input_navigation_design.md` 的 `I15` 专项增强，不属于 `I14` 首版）。
- 根据校验错误强制停留在当前格。

若后续确需增强，应单独确认交互规则后再实现。
